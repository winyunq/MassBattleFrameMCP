MassBattleEffectAssetMCPApi.h

Manage Niagara, Cascade, material and Blueprint effect assets and renderer defaults.

查询并识别 Niagara、Cascade、材质和蓝图等特效资产，读取类型化摘要或确定性文本，再执行复制、未保存副本回滚或显式删除。渲染器接口读写 MassBattle FX 渲染器类默认值，包括 Niagara 系统、Burst 数据通道、特效子类型和批量大小。 调用者从查询和检查结果取得真实资产路径与配置，再选择对应的资产操作或渲染配置工具。参数、默认行为和 JSON 返回结果在各公开函数中说明。

Class

UMassBattleEffectAssetMCPApi

Inspect and copy effect assets and configure batch renderer class defaults.

These tools intentionally do not perform one-click conversion. They provide asset discovery, text inspection, duplication, and MassBattle FX renderer default writes so a skill can assemble a conversion workflow.

MCP Batch Fx Read Renderer Defaults

UMassBattleEffectAssetMCPApi::MCP_BatchFxReadRendererDefaults

Inspect effect settings inherited by newly placed renderers.

Description

Reads the class-default object of the selected MassBattle FX renderer class. These defaults are the authoring settings inherited by newly placed renderer actors.

Inputs

NameTypeRemarks
TargetClassPathconst FString &Unreal Blueprint/class path resolving to AMassBattleFxRenderer or a derived class.

Returns

The class defaults in defaults, including its Blueprint/default object, effect system, Burst channel, subtype, batch size and cooldown; unassigned asset references are empty strings.

MCP Batch Fx Set Renderer Defaults

UMassBattleEffectAssetMCPApi::MCP_BatchFxSetRendererDefaults

Set shared effect systems, channels and batch settings for newly placed renderers.

Description

Updates the renderer class-default object, recompiles its Blueprint when applicable, marks the package dirty and optionally saves it. Empty system/channel paths keep the existing reference; numeric sentinel values keep the corresponding existing setting.

Inputs

NameTypeRemarks
TargetClassPathconst FString &MassBattle FX renderer Blueprint/class path whose defaults will be edited.
NiagaraSystemPathconst FString &NiagaraSystem object path; an empty string keeps the existing system.
NdcBurstFxPathconst FString &NiagaraDataChannelAsset object path; an empty string keeps the current Burst channel.
SubTypeint32FX subtype index. A negative value keeps the existing index.
RenderBatchSizeint32Positive batch size, or a non-positive value to keep it. The MCP tool default is 2048.
PoolingCooldownfloatPooling cooldown in seconds; a negative value keeps it. The MCP tool default is 3.0.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

The effective renderer class and effect settings after the update, including system, channel, subtype, batch size and cooldown; saved identifies persistence.

MCP Effect Asset Soft Delete

UMassBattleEffectAssetMCPApi::MCP_EffectAssetSoftDelete

Check asset references before moving it to the trash folder.

Description

Builds a trash-move report, checks hard/soft referencers and blocks a referenced asset unless the explicit corresponding override is supplied. The default dry run returns the proposed destination; an executable request uses AssetTools to move the asset and reports the outcome.

Inputs

NameTypeRemarks
AssetPathconst FString &Unreal object path of the existing effect-related asset.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. dry_run defaults to true; preview_only also requests a preview. trash_package_path/trash_root select the destination. allow_referenced and allow_unsafe_asset_move/force explicitly opt into the supported exceptional moves.

Returns

A trash-move report: applicable and blocked_reason explain executability, trash_path is the proposed destination, and moved records execution when requested.

MCP Effect Discard Unsaved Duplicate

UMassBattleEffectAssetMCPApi::MCP_EffectDiscardUnsavedDuplicate

Roll back effect copies left unsaved in this editor session.

Create the unsaved duplicate with MCP Effect Duplicate Asset using bSaveAssets=false.

Description

Discards a duplicate only when this MCP editor session tracked it as unsaved, it is still loaded in a dirty /Game/ package, and it has not crossed the persisted-asset boundary. This supports rolling back a failed conversion before saving.

Inputs

NameTypeRemarks
AssetPathconst FString &Exact object path returned by the duplicate tool for an unsaved duplicate in this editor session.

Returns

The discarded asset and package, with discarded indicating removal and deleted_count reporting the number removed.

MCP Effect Duplicate Asset

UMassBattleEffectAssetMCPApi::MCP_EffectDuplicateAsset

Preserve the source effect by creating a copy for conversion.

Description

Uses AssetTools to duplicate the source asset into the requested package and name. The duplicate preserves the source-owned visual data. When left unsaved, it is tracked by this editor session so the matching discard tool can roll it back.

Inputs

NameTypeRemarks
SourceAssetPathconst FString &Unreal object path of the existing source effect asset.
NewAssetNameconst FString &Name of the new duplicate asset.
PackagePathconst FString &Destination Unreal package folder, such as /Game/Effects.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

The duplicate's object path and package, with saved indicating whether it has been persisted.
