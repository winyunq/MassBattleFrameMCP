UMassBattleProjectileMCPApi

Maintain projectile movement, damage, triggers and lifecycle effect settings.

This API edits projectile gameplay assets only. Linked one-shot and attached visuals remain MassBattle Batch FX/Niagara work and are authored through the effect APIs.

MCP Projectile Create

UMassBattleProjectileMCPApi::MCP_ProjectileCreate

Create a validated projectile config from a template or class defaults.

Description

Builds a transient preview from the requested template or class defaults, applies initial source-aligned data and validates it before creating the real projectile DataAsset. It rejects an invalid or occupied destination instead of replacing that asset.

Inputs

NameTypeRemarks
CreateSpecJsonconst FString &JSON with asset_name (alias name), package_path (alias target_package_path) and optional template_path/template plus initial projectile data. package_path must be an Unreal package path beginning with /.
bSaveAssetsbool= trueWhether to save the assets modified or created by this operation to disk.

Returns

The new asset and template paths, resulting configuration and changed field paths; saved indicates whether the asset was written to disk.

MCP Projectile Delete

UMassBattleProjectileMCPApi::MCP_ProjectileDelete

Check references before previewing or executing asset removal.

Description

Builds a deletion/trash move report and checks references. dry_run=true returns the report without changing the DataAsset; an explicit executable request performs the selected supported mode and returns the actual move/delete outcome.

Inputs

NameTypeRemarks
ProjectilePathconst FString &Unreal object path of the projectile configuration to remove.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. dry_run defaults to true. mode chooses the supported deletion path; trash_root selects trash placement. Referenced/unsafe/hard operations require their corresponding allow_referenced, allow_unsafe_asset_move or allow_hard_delete option.

Returns

The removal report with referencers, applicability and blocking reasons; execution adds the actual trash destination or deletion count.

MCP Projectile Get

UMassBattleProjectileMCPApi::MCP_ProjectileGet

Inspect active projectile data with optional validation and references.

Description

Loads one projectile DataAsset and returns source-aligned authored data. The active view selects fields relevant to the configured movement and damage modes; the full view can include inactive fields. Validation and referencing assets can be included in the same read.

Inputs

NameTypeRemarks
ProjectilePathconst FString &Unreal object path of the projectile configuration DataAsset.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. view/detail and include_inactive select the field view; include_validation and include_referencers request the corresponding reports.

Returns

The authored configuration in data and its movement and damage modes; view identifies the field view, with validation and referencers included when requested.

MCP Projectile Get Schema

UMassBattleProjectileMCPApi::MCP_ProjectileGetSchema

Obtain field types and write rules for movement and damage modes.

Description

Reflects projectile field names, types, enums, edit conditions and tooltips. It returns movement/damage-mode field groups and the source-aligned write, damage-ownership and lifecycle rules needed to form a valid patch. Array writes merge by index and reject appending by default; options.append_arrays=true permits append and options.array_mode=replace requests replacement. The returned ownership rule assigns normal projectile attack damage to the projectile DataAsset with Agent Attack.TimeOfHitAction=None; the lifecycle rule identifies duplicate full explosions in OnHit and OnRemoval.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. depth selects the nested schema expansion depth.

Returns

Field definitions and mode-specific field groups, together with array-write, damage-ownership and lifecycle rules.

MCP Projectile Write

UMassBattleProjectileMCPApi::MCP_ProjectileWrite

Validate a partial update before changing the projectile asset.

Description

Applies the partial source-aligned patch to a transient copy and validates the candidate before mutating the real projectile configuration. Omitted fields are retained; use the schema write rules when changing arrays or nested authored structs.

Inputs

NameTypeRemarks
ProjectilePathconst FString &Unreal object path of the existing projectile DataAsset.
PatchJsonconst FString &Nonempty partial projectile JSON using real source field names. Read the projectile schema for enum values, conditions and array write rules. options.append_arrays and options.array_mode explicitly select array append/replacement behavior.
bSaveAssetsbool= trueWhether to save the assets modified or created by this operation to disk.

Returns

The actual changed field paths, resulting configuration and validation report; saved identifies persistence, and failures report field, preflight or save errors.

See also

MCP Projectile Get Schema for exact field/write rules.
