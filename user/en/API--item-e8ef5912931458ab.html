UMassBattleProjectileMCPApi

Source-aligned CRUD, schema, and validation primitives for UMassBattleProjectileConfigDataAsset.

This API edits projectile gameplay assets only. Linked one-shot and attached visuals remain MassBattle Batch FX/Niagara work and are authored through the effect APIs.

MCP Projectile Create(CreateSpecJson, bSaveAssets)

UMassBattleProjectileMCPApi::MCP_ProjectileCreate

Create a projectile DataAsset from a template or class defaults.

Description

MCP tool: projectile_create. Builds a transient preview from the requested template or class defaults, applies initial source-aligned data and validates it before creating the real projectile DataAsset. It rejects an invalid or occupied destination instead of replacing that asset.

Inputs

NameTypeRemarks
CreateSpecJsonconst FString &JSON with asset_name (alias name), package_path (alias target_package_path) and optional template_path/template plus initial projectile data. package_path must be an Unreal package path beginning with /.
bSaveAssetsbool= trueWhether to save the modified or newly created assets to disk. The MCP tool supplies its documented save_assets default; false leaves changes in editor memory.

Returns

JSON with success, asset_path, template_path, saved, changed_paths and data. Invalid input, preflight failures or asset creation errors return success=false/error.

MCP Projectile Delete(ProjectilePath, OptionsJson)

UMassBattleProjectileMCPApi::MCP_ProjectileDelete

Plan or delete a projectile DataAsset; dry_run=true by default.

Description

MCP tool: projectile_delete. Builds a deletion/trash move report and checks references. dry_run=true returns the report without changing the DataAsset; an explicit executable request performs the selected supported mode and returns the actual move/delete outcome.

Inputs

NameTypeRemarks
ProjectilePathconst FString &Unreal object path of the projectile configuration to remove.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. dry_run defaults to true. mode chooses the supported deletion path; trash_root selects trash placement. Referenced/unsafe/hard operations require their corresponding allow_referenced, allow_unsafe_asset_move or allow_hard_delete option.

Returns

JSON with dry_run, mode, source_path, referencers, applicable and blocked_reason; executed requests add moved/trash_path or deleted/deleted_count and any error.

UMassBattleProjectileMCPApi::MCP_ProjectileGet

Read one projectile DataAsset in active-only or full source-aligned form.

Description

MCP tool: projectile_get. Loads one projectile DataAsset and returns source-aligned authored data. The active view selects fields relevant to the configured movement and damage modes; the full view can include inactive fields. Validation and referencing assets can be included in the same read.

Inputs

NameTypeRemarks
ProjectilePathconst FString &Unreal object path of the projectile configuration DataAsset.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. view/detail and include_inactive select the field view; include_validation and include_referencers request the corresponding reports.

Returns

JSON with success, asset_name, object_path, class, view, movement_mode, damage_mode and data, plus requested validation/referencers.

MCP Projectile Get Schema(OptionsJson)

UMassBattleProjectileMCPApi::MCP_ProjectileGetSchema

Read projectile field types, enums, conditions, tooltips, and write rules.

Description

MCP tool: projectile_get_schema. Reflects projectile field names, types, enums, edit conditions and tooltips. It returns movement/damage-mode field groups and the source-aligned write, damage-ownership and lifecycle rules needed to form a valid patch. Array writes merge by index and reject appending by default; options.append_arrays=true permits append and options.array_mode=replace requests replacement. The returned ownership rule assigns normal projectile attack damage to the projectile DataAsset with Agent Attack.TimeOfHitAction=None; the lifecycle rule identifies duplicate full explosions in OnHit and OnRemoval.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. depth selects the nested schema expansion depth.

Returns

JSON with success, class, field_count, fields, movement_mode_fields, damage_mode_fields, array_write_rule, damage_ownership_rule and lifecycle_rule.

Description

MCP Projectile Write(ProjectilePath, PatchJson, bSaveAssets)

UMassBattleProjectileMCPApi::MCP_ProjectileWrite

Union-write source-aligned projectile data after transient preflight and validation.

Description

MCP tool: projectile_write. Applies the partial source-aligned patch to a transient copy and validates the candidate before mutating the real projectile configuration. Omitted fields are retained; use the schema write rules when changing arrays or nested authored structs.

Inputs

NameTypeRemarks
ProjectilePathconst FString &Unreal object path of the existing projectile DataAsset.
PatchJsonconst FString &Nonempty partial projectile JSON using real source field names. Read the projectile schema for enum values, conditions and array write rules. options.append_arrays and options.array_mode explicitly select array append/replacement behavior.
bSaveAssetsbool= trueWhether to save the modified or newly created assets to disk. The MCP tool supplies its documented save_assets default; false leaves changes in editor memory.

Returns

JSON with success, asset_path, saved, changed_paths, data and validation, or success=false/error for invalid fields, failed preflight or saving.

MCP Projectile Get Schema for exact field/write rules.
