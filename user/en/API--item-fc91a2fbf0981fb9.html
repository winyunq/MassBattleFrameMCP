UMassBattleUnitEditorMCPApi

Build VAT units from skeletal meshes or Actors and organize the resulting assets.

The original MassBattleEditor module exposes Blueprint-callable editor tools for converting purchased assets into MassBattle-ready data. This API composes those tools into reviewable MCP editor operations.

MCP Editor Apply Create Vat Unit

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnit

Create a unit that plays baked skeletal animation through a static mesh.

Description

The skeletal mesh is converted into a static mesh with LODs and instances of the parent material. For each LOD, bone or vertex mode samples the animations into VAT textures; these textures, an animation-index texture and decoding parameters are assigned to that LOD's materials so the static mesh can reproduce the animation. The renderer receives the mesh, Niagara system and subtype; the unit receives Visualize.RendererClass, AnimShared.AnimData and the baked animation sample rate. New units are created through MCP Unit Create, then configuration is written through MCP Unit Plan Merge Update and MCP Unit Apply Plan.

Inputs

NameTypeRemarks
SpecJsonconst FString &JSON specification containing skeletal_mesh, unit_name, target_package_path, parent_material, source_renderer_class, niagara_system, vat_sample_rate and a nonempty animations category-to-AnimSequence mapping. target_unit selects an existing unit; otherwise template_unit, target_unit_package_path and subtype describe creation. dry_run/preview_only selects a preview; overwrite_existing controls replacement of generated outputs. compact_response selects result detail: false in this native entry, true by default in the MCP wrapper, with an explicit JSON value taking precedence.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

Generation-step results or a compact summary; previews return the plan and validation. Validation failures are described by validation.valid and validation.issues; execution_steps records completed and failed steps when execution stops.

Notes

Validation is performed automatically; diagnostic plan/validate calls are optional before this primary entry.

MCP Editor Apply Create Vat Unit From Actor

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnitFromActor

Combine an Actor's components and weapon into an animated VAT unit.

Description

The resolved Actor components and weapon are assembled into an animation-compatible skeletal mesh. That mesh and the resolved VAT specification are then passed to MCP Editor Apply Create Vat Unit to build the unit resources.

Inputs

NameTypeRemarks
SpecJsonconst FString &JSON object with actor_class, optional component_overrides and VAT generation settings. assembled_skeletal_mesh_path selects the assembly output; otherwise target_package_path and unit_name determine it, with assembled_skeletal_mesh_name overriding the name. overwrite_existing selects replacement and dry_run/preview_only selects preview. compact_response controls response detail; its MCP wrapper default is true and an explicit JSON value takes precedence.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

The plan for a preview request, or the assembled skeletal mesh, resolved VAT specification and vat_result after execution; failures report the relevant assembly or VAT step.

See also

MCP Editor Plan Create Vat Unit From Actor for the resolved inputs and assembly preview.

MCP Editor Apply Create Vat Unit From Selection

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnitFromSelection

Resolve selected source assets into a specification and generate a VAT unit.

Description

Selection resolution produces the mesh, animation and output settings used by MCP Editor Apply Create Vat Unit. The resolved selection and specification are included with the generation result.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON options for selection resolution and VAT generation. selected_assets overrides the current selection. compact_response controls response detail; its MCP wrapper default is true and an explicit JSON value takes precedence.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

The resolved selection and specification together with apply_result or apply_summary; failures identify selection resolution or generation problems.

MCP Editor Apply Organize Unit Assets

UMassBattleUnitEditorMCPApi::MCP_EditorApplyOrganizeUnitAssets

Move a unit and its linked source and generated assets into a style layout.

Description

Rebuilds the same organization plan and returns it by default because dry_run=true. With dry_run=false it executes the eligible AssetTools moves and reports each performed move and actual failure.

Inputs

NameTypeRemarks
UnitPathconst FString &Unreal object path of the existing MassBattle unit config or supported Unit Source Actor Blueprint.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. Uses the same layout options as the organization planner. dry_run defaults to true; preview_only is also accepted.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

The move plan for a preview, or per-step results and the actual moved count after execution; failure reports retain the performed move results.

MCP Editor Inspect Actor Assembly

UMassBattleUnitEditorMCPApi::MCP_EditorInspectActorAssembly

Check component materials and weapon bones before assembling an Actor.

Description

Spawns/resolves the requested Actor for inspection, evaluates included skeletal/static components, effective materials and weapon bind bones, and reports whether the assembly can be produced. Bounds are reported in root-skeleton model space without recentering. No generated assets are written.

Inputs

NameTypeRemarks
ActorPathconst FString &Actor Blueprint or class object path. When supplied, it becomes actor_class in the inspection spec.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. Optional component_overrides selects assembly participation and component-specific authoring overrides.

Returns

An assembly inspection containing components, materials, weapon binding information, bounds and issues; can_assemble indicates assembly feasibility.

MCP Editor Inspect Vat Animation

UMassBattleUnitEditorMCPApi::MCP_EditorInspectVatAnimation

Check skin weights, frame motion, lookup UVs and animation settings.

Description

Loads the VAT data and referenced skeletal/static meshes, audits deforming skin weights, position-frame motion and lookup UVs, and compares baked animation paths with the selected soldier animation profile. This entry reports evidence without baking or editing assets.

Inputs

NameTypeRemarks
SpecJsonconst FString &JSON containing vat_data_asset (or anim_to_texture_data_asset); skeletal_mesh and static_mesh select the meshes explicitly. ground_tolerance_uu configures the ground audit tolerance in Unreal units.

Returns

The VAT animation audit, including skin-weight, frame-motion, animation-resource and UV evidence together with detected issues.

MCP Editor Plan Create Vat Unit

UMassBattleUnitEditorMCPApi::MCP_EditorPlanCreateVatUnit

Inspect source assets and output layout before VAT generation.

Description

Output paths are derived from the source mesh, unit name and target layout. Recipe defaults, generated mesh/animation/LOD references and the explicit unit_patch are merged in that order to form the proposed unit configuration.

Inputs

NameTypeRemarks
SpecJsonconst FString &JSON object describing the source skeletal_mesh and unit_name, target_package_path and optional recipe_id/style_profile, animation discovery paths and unit_patch. target_unit selects an existing unit; template_unit and target_unit_package_path describe a new unit.

Returns

The resolved output layout, discovered inputs and proposed generation steps, with applicability and warnings describing unresolved problems.

See also

MCP Editor Apply Create Vat Unit for the primary generation entry.

MCP Editor Plan Create Vat Unit From Actor

UMassBattleUnitEditorMCPApi::MCP_EditorPlanCreateVatUnitFromActor

Inspect an Actor assembly plan and its resolved VAT specification.

Description

Actor inspection supplies component meshes, materials and weapon bindings. Animation, sample-rate and LOD settings are resolved together with the proposed assembled mesh path to produce resolved_vat_spec.

Inputs

NameTypeRemarks
SpecJsonconst FString &JSON object with actor_class, optional component_overrides and the desired output folder/name. VAT settings use the fields documented by MCP Editor Apply Create Vat Unit; animation, sample-rate and LOD values are resolved from the Actor and supplied settings.

Returns

The resolved_vat_spec, proposed assembled mesh and resolved animation, sample-rate and LOD settings; applicable and issues describe executability.

MCP Editor Plan Organize Unit Assets

UMassBattleUnitEditorMCPApi::MCP_EditorPlanOrganizeUnitAssets

Inspect destination folders for a unit and its linked assets.

Description

Resolves the style layout and discovers the unit and linked generated/source assets selected by the organization policy. It calculates source/destination moves and collision status without moving or saving assets.

Inputs

NameTypeRemarks
UnitPathconst FString &Unreal object path of the existing MassBattle unit config or supported Unit Source Actor Blueprint.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. style_profile chooses defaults; target_root or target_package_path selects the destination. unit_name, use_family_folder, generated_folder_name/target_folder_name and managed_roots customize the existing layout policy.

Returns

A move list giving source paths, destination paths and checks for each asset, together with the resolved style layout.

UMassBattleUnitEditorMCPApi::MCP_EditorValidateCreateVatUnit

Check required VAT fields and referenced assets.

Description

Resolves the skeletal mesh, parent material, renderer and Niagara asset references, checks the animation category mapping and VAT settings, and combines the findings with the planned execution steps.

Inputs

NameTypeRemarks
SpecJsonconst FString &VAT generation specification using the fields documented by MCP Editor Apply Create Vat Unit. Mesh, animation, material, renderer, output and subtype settings are checked without generating assets.

Returns

The validation conclusion in valid, field problems in issues and proposed workflow in execution_preview.
