MCP Editor Apply Create Vat Unit(SpecJson, bSaveAssets)

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnit

Generate a VAT unit from a specification.

Description

MCP tool: editor_apply_create_vat_unit. Validates complete canonical inputs before running the MassBattleTools DoAll-equivalent skeletal-mesh VAT workflow. It creates or updates the required VAT data, materials, renderer and unit through MassBattleEditor. dry_run/preview_only requests validation and execution preview instead of asset writes. The MCP tool defaults compact_response to true; an explicit value in spec overrides that default.

Inputs

NameTypeRemarks
SpecJsonconst FString &Complete canonical VAT generation JSON. Use canonical fields skeletal_mesh, unit_name, target_package_path, parent_material, source_renderer_class, niagara_system, vat_sample_rate and a nonempty animations category-to-AnimSequence mapping. Supply target_unit to update a unit, or template_unit, target_unit_package_path and subtype to create one. Strict execution rejects legacy aliases and missing-asset/static fallback switches. Optional dry_run/preview_only controls preview, overwrite_existing controls existing generated outputs, and compact_response selects compact results.
bSaveAssetsboolWhether to save the modified or newly created assets to disk. The MCP tool supplies its documented save_assets default; false leaves changes in editor memory.

Returns

JSON with success, dry_run, save_assets and execution_steps or a compact apply summary. Validation failures include valid=false, issues and execution_preview; step failures return their actual result.

Notes

Validation is performed automatically; diagnostic plan/validate calls are optional before this primary entry.

MCP Editor Apply Create Vat Unit From Actor(SpecJson, bSaveAssets)

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnitFromActor

Assemble an Actor into a VAT unit.

Description

MCP tool: editor_apply_create_vat_unit_from_actor. Builds and validates the Actor assembly plan, creates the animation-compatible assembled SkeletalMesh, and passes the resolved canonical spec to the primary VAT generation entry. dry_run/preview_only returns the plan without creating outputs. The MCP tool defaults compact_response to true, overridable in spec.

Inputs

NameTypeRemarks
SpecJsonconst FString &JSON with actor_class and optional component_overrides, plus the canonical VAT unit fields. assembled_skeletal_mesh_path chooses the assembly asset explicitly; otherwise target_package_path and unit_name produce SKM_<unit_name>_Assembled, overridable by assembled_skeletal_mesh_name. overwrite_existing controls replacing an assembly output. Includes the canonical VAT inputs documented by the Actor planning entry, plus dry_run/preview_only and compact_response.
bSaveAssetsboolWhether to save the modified or newly created assets to disk. The MCP tool supplies its documented save_assets default; false leaves changes in editor memory.

Returns

JSON with the plan or assembly result, skeletal_mesh, resolved_vat_spec and vat_result. Inapplicable plans or failed assembly/VAT steps return their actual errors.

See also

MCP Editor Plan Create Vat Unit From Actor for the resolved inputs and assembly preview.

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnitFromSelection

Generate a VAT unit from selected assets.

Description

MCP tool: editor_apply_create_vat_unit_from_selection. Builds the canonical VAT spec from the current selection or selected_assets and executes the same primary DoAll generation workflow. The MCP tool defaults compact_response to true; explicit options override that value. The selection and resolved inputs remain visible in the response.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. selected_assets overrides editor selection; generation options and compact_response are passed to the resolved VAT workflow.
bSaveAssetsboolWhether to save the modified or newly created assets to disk. The MCP tool supplies its documented save_assets default; false leaves changes in editor memory.

Returns

JSON with success, selection, resolved_spec and apply_result or apply_summary; failed selection resolution or generation returns the corresponding error.

UMassBattleUnitEditorMCPApi::MCP_EditorApplyOrganizeUnitAssets

Apply a unit asset organization plan.

Description

MCP tool: editor_apply_organize_unit_assets. Rebuilds the same organization plan and returns it by default because dry_run=true. With dry_run=false it executes the eligible AssetTools moves and reports each performed move and actual failure.

Inputs

NameTypeRemarks
UnitPathconst FString &Unreal object path of the existing MassBattle unit config or supported Unit Source Actor Blueprint.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. Uses the same layout options as the organization planner. dry_run defaults to true; preview_only is also accepted.
bSaveAssetsboolWhether to save the modified or newly created assets to disk. The MCP tool supplies its documented save_assets default; false leaves changes in editor memory.

Returns

JSON with dry_run, plan, execution_steps, moved_count and moved; execution failures include success=false/error and the actual move report.

UMassBattleUnitEditorMCPApi::MCP_EditorInspectActorAssembly

Inspect an Actor's meshes and weapon bindings.

Description

MCP tool: editor_inspect_actor_assembly. Spawns/resolves the requested Actor for inspection, evaluates included skeletal/static components, effective materials and weapon bind bones, and reports whether the assembly can be produced. Bounds are reported in root-skeleton model space without recentering. No generated assets are written.

Inputs

NameTypeRemarks
ActorPathconst FString &Actor Blueprint or class object path. When supplied, it becomes actor_class in the inspection spec.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. Optional component_overrides selects assembly participation and component-specific authoring overrides.

Returns

JSON with success, inspection_type, actor_class, root_component, component counts, components, body_bounds, can_assemble and issues.

MCP Editor Inspect Vat Animation(SpecJson)

UMassBattleUnitEditorMCPApi::MCP_EditorInspectVatAnimation

Inspect VAT animation baking results.

Description

MCP tool: editor_inspect_vat_animation. Loads the VAT data and referenced skeletal/static meshes, audits deforming skin weights, position-frame motion and lookup UVs, and compares baked animation paths with the selected soldier animation profile. This entry reports evidence without baking or editing assets.

Inputs

NameTypeRemarks
SpecJsonconst FString &JSON containing vat_data_asset (or anim_to_texture_data_asset); skeletal_mesh and static_mesh select the meshes explicitly. ground_tolerance_uu configures the ground audit tolerance in Unreal units.

Returns

The VAT animation audit JSON, including validity, deforming-weight and motion findings, animation evidence and mesh/UV issues. Invalid JSON or unresolved inputs return success=false and error.

MCP Editor Plan Create Vat Unit(SpecJson)

UMassBattleUnitEditorMCPApi::MCP_EditorPlanCreateVatUnit

Preview VAT unit generation.

Description

MCP tool: editor_plan_create_vat_unit. Resolves source mesh, recipe/style settings, animation and texture discovery, and generated-asset layout without writing generated assets. This is a diagnostic preview; its discovery aliases or inferred values do not replace the complete canonical fields required by strict apply.

Inputs

NameTypeRemarks
SpecJsonconst FString &JSON describing the source skeletal_mesh and unit_name, discovery paths, optional recipe_id/style_profile and intended generated asset layout. Use canonical fields skeletal_mesh, unit_name, target_package_path, parent_material, source_renderer_class, niagara_system, vat_sample_rate and a nonempty animations category-to-AnimSequence mapping. Supply target_unit to update a unit, or template_unit, target_unit_package_path and subtype to create one. Strict execution rejects legacy aliases and missing-asset/static fallback switches.

Returns

The planning JSON with resolved_layout, discovery, applicability, warnings and proposed steps, or success=false and error for invalid input/profile resolution.

See also

MCP Editor Apply Create Vat Unit for the primary generation entry.

MCP Editor Plan Create Vat Unit From Actor(SpecJson)

UMassBattleUnitEditorMCPApi::MCP_EditorPlanCreateVatUnitFromActor

Preview VAT unit generation from an Actor.

Description

MCP tool: editor_plan_create_vat_unit_from_actor. Inspects the Actor assembly, resolves animation/sample-rate/LOD defaults, validates the required VAT fields and assembly output, then returns a canonical resolved_vat_spec. It reports collisions and assembly issues without creating generated assets.

Inputs

NameTypeRemarks
SpecJsonconst FString &JSON with actor_class and optional component_overrides, plus the canonical VAT unit fields. assembled_skeletal_mesh_path chooses the assembly asset explicitly; otherwise target_package_path and unit_name produce SKM_<unit_name>_Assembled, overridable by assembled_skeletal_mesh_name. overwrite_existing controls replacing an assembly output. Required VAT settings include unit_name, target_package_path, parent_material, source_renderer_class, niagara_system, positive vat_sample_rate, animations, and either target_unit or template_unit/target_unit_package_path/subtype.

Returns

JSON with applicable, assembled_skeletal_mesh, assembly_status, inspection, animation_resolution, vat_sample_rate_resolution, vat_lod_resolution, resolved_vat_spec and issues.
