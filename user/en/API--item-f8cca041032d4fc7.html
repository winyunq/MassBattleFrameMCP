MassBattleNiagaraMCPApi.h

Inspect and edit Niagara systems for MassBattle batch effect conversion.

以 UE 5.8 的 Niagara 编辑器能力为完整功能基线，读取系统、发射器、渲染器、模块引脚和脚本图，再通过显式属性写入、堆栈输入与图编辑把现有效果接入 MassBattle 批处理。 改造过程使用源系统与目标系统的语义比较、图连接证据和编译诊断检查保留结果；写入和删除分别使用各自的公开工具。各函数说明其选择器、操作 JSON、保存行为及返回报告。

Class

UMassBattleNiagaraMCPApi

Inspect and edit effect emitters, modules, parameters and graph connections.

These tools intentionally behave like asset/graph command-line primitives: query, read, export text, union-merge write, and explicit delete.

MCP Niagara Add Sprite Renderer

UMassBattleNiagaraMCPApi::MCP_NiagaraAddSpriteRenderer

Add a sprite renderer with material and visibility bindings to an existing emitter.

Description

Allocates and configures a sprite renderer on an existing emitter, including its material, user-parameter bindings, sort order and visibility. It adds the renderer without rewriting the emitter graph, then finishes compilation and optional saving.

Inputs

NameTypeRemarks
SystemPathconst FString &Unreal object path of the existing NiagaraSystem.
EmitterNameconst FString &Name of the existing emitter receiving the new renderer.
RendererJsonconst FString &JSON with material and optional material_user_parameter, enabled_user_parameter, sort_order and renderer_visibility.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

The new renderer's add/compile report and persistence result; failures identify target, material or creation problems.

MCP Niagara Apply Graph Edit

UMassBattleNiagaraMCPApi::MCP_NiagaraApplyGraphEdit

Batch-edit graph connections and stacks, then check conversion results.

Description

Validates ordered operation records and ids, executes explicit graph/stack edits, compiles once and checks source preservation before saving. Operations include emitter copying, user values/data interfaces, module/assignment insertion, pin connection/disconnection/rewiring and stack-input edits. Empty operations requests compile/validation only.

Inputs

NameTypeRemarks
SystemPathconst FString &Unreal object path of the existing NiagaraSystem.
EditJsonconst FString &JSON with an operations array (alias edits). Each object supplies op/type, optional unique id and the fields required for its operation and source-preservation policy.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

Ordered edit outcomes, compile diagnostics, source-preservation findings and saved state; failures report the operation or validation error.

MCP Niagara Compare Systems

UMassBattleNiagaraMCPApi::MCP_NiagaraCompareSystems

Check whether a copy or conversion preserves the source system's structure.

Description

Loads two different systems and compares source-neutral semantic fingerprints. exact mode checks a duplicate; translation mode applies the configured preservation rules for an intended conversion. Compile readiness/error/warning options control the corresponding result checks.

Inputs

NameTypeRemarks
SourceSystemPathconst FString &Unreal object path of the reference NiagaraSystem.
TargetSystemPathconst FString &Unreal object path of a different NiagaraSystem to compare against the source.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. mode must be exact or translation. require_ready_to_run, require_no_compile_errors and require_no_warnings select compile-state requirements.

Returns

Source-preservation findings, source/target emitter and renderer counts, unexpected removed links and compile readiness.

MCP Niagara Merge Write

UMassBattleNiagaraMCPApi::MCP_NiagaraMergeWrite

Patch system, emitter or renderer properties while retaining other values.

Description

Resolves explicit system, emitter-data or renderer targets and union-merges requested reflected property values. Omitted properties are retained. Each result records target resolution and before/after values; saving is optional.

Inputs

NameTypeRemarks
SystemPathconst FString &Unreal object path of the existing NiagaraSystem.
PatchJsonconst FString &JSON containing patches, or one patch object. Each patch selects a target, property/path and value_text or value. Use real reflected property names from read_all.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

Per-patch results identifying resolved targets, before/after values and saved state, with errors on failed patches.

Locate Niagara systems by name or folder.

Obtain node, pin and link IDs for precise graph edits.

Reads system or standalone NiagaraScript graphs and returns stable node/pin identifiers and explicit links. Optional stack-input topology and compile-state reports provide the identities and diagnostics used by the graph-edit tool.

Inputs

Identify a module and its pins before editing them.

MCP Niagara Set Module Pin

UMassBattleNiagaraMCPApi::MCP_NiagaraSetModulePin

Use a node or module selector to adjust an input pin's default.

Description

Resolves one function-call module and named pin, then writes its default value. Linked pins require allow_linked=true because the default may be ignored; non-input pins require allow_output=true. The report identifies the selected node and old/new text.

Inputs

NameTypeRemarks
SystemPathconst FString &Unreal object path of the existing NiagaraSystem.
SelectorJsonconst FString &JSON using emitter, module/function_name, node_guid or module_index; allow_linked and allow_output opt into the corresponding writes.
PinNameconst FString &Exact pin name returned by module inspection.
ValueTextconst FString &Default value in the selected pin type text/import syntax.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

The selected emitter, module and pin, its before/after defaults, existing connection count and saved state.
