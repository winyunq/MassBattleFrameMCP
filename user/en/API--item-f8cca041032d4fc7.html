MassBattleNiagaraMCPApi.h

用于 MassBattle 特效批处理改造的 Niagara MCP 接口（UE 5.8）。

以 UE 5.8 的 Niagara 编辑器能力为完整功能基线，读取系统、发射器、渲染器、模块引脚和脚本图，再通过显式属性写入、堆栈输入与图编辑把现有效果接入 MassBattle 批处理。 改造过程使用源系统与目标系统的语义比较、图连接证据和编译诊断检查保留结果；写入和删除分别使用各自的公开工具。各函数说明其选择器、操作 JSON、保存行为及返回报告。

Class

UMassBattleNiagaraMCPApi

Low-level Niagara MCP tools.

These tools intentionally behave like asset/graph command-line primitives: query, read, export text, union-merge write, and explicit delete.

MCP Niagara Add Sprite Renderer(SystemPath, EmitterName, RendererJson, bSaveAssets)

UMassBattleNiagaraMCPApi::MCP_NiagaraAddSpriteRenderer

Add one configured sprite renderer to an existing Niagara emitter.

Description

MCP tool: niagara_add_sprite_renderer. Allocates and configures a sprite renderer on an existing emitter, including its material, user-parameter bindings, sort order and visibility. It adds the renderer without rewriting the emitter graph, then finishes compilation and optional saving.

Inputs

NameTypeRemarks
SystemPathconst FString &Unreal object path of the existing NiagaraSystem.
EmitterNameconst FString &Name of the existing emitter receiving the new renderer.
RendererJsonconst FString &JSON with material and optional material_user_parameter, enabled_user_parameter, sort_order and renderer_visibility.
bSaveAssetsboolWhether to save the modified system. The MCP tool default is save_assets=false.

Returns

The renderer-add/compile report with the created renderer and saved state. Invalid JSON, unresolved emitters/materials or allocation failures return success=false/error.

MCP Niagara Apply Graph Edit(SystemPath, EditJson, bSaveAssets)

UMassBattleNiagaraMCPApi::MCP_NiagaraApplyGraphEdit

Apply ordered Niagara graph edits, compile once, validate preservation, and optionally save.

Description

MCP tool: niagara_apply_graph_edit. Validates ordered operation records and ids, executes explicit graph/stack edits, compiles once and checks source preservation before saving. Operations include emitter copying, user values/data interfaces, module/assignment insertion, pin connection/disconnection/rewiring and stack-input edits. Empty operations requests compile/validation only.

Inputs

NameTypeRemarks
SystemPathconst FString &Unreal object path of the existing NiagaraSystem.
EditJsonconst FString &JSON with an operations array (alias edits). Each object supplies op/type, optional unique id and the fields required for its operation and source-preservation policy.
bSaveAssetsboolWhether to save the modified system. The MCP tool default is save_assets=false.

Returns

The ordered operation, compile and preservation-validation report with actual edit results and saved state. Malformed operations, failed edits or failed validation report their errors.

MCP Niagara Compare Systems(SourceSystemPath, TargetSystemPath, OptionsJson)

UMassBattleNiagaraMCPApi::MCP_NiagaraCompareSystems

Compare a source Niagara system with a duplicate/translation using source-neutral fingerprints.

Description

MCP tool: niagara_compare_systems. Loads two different systems and compares source-neutral semantic fingerprints. exact mode checks a duplicate; translation mode applies the configured preservation rules for an intended conversion. Compile readiness/error/warning options control the corresponding result checks.

Inputs

NameTypeRemarks
SourceSystemPathconst FString &Unreal object path of the reference NiagaraSystem.
TargetSystemPathconst FString &Unreal object path of a different NiagaraSystem to compare against the source.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. mode must be exact or translation. require_ready_to_run, require_no_compile_errors and require_no_warnings select compile-state requirements.

Returns

The comparison JSON with preservation checks, source/target emitter and renderer counts, unexpected_removed_edges and readiness. Invalid input or identical source/target assets return success=false/error.

MCP Niagara Delete(SystemPath, DeleteJson, bSaveAssets)

UMassBattleNiagaraMCPApi::MCP_NiagaraDelete

Run explicit Niagara delete operations such as renderer or user-parameter removal.

Description

MCP tool: niagara_delete. Executes explicit renderer removal, user-parameter removal or emitter disabling on the selected system. Each action identifies its target and reports the actual removed/changed result.

Inputs

NameTypeRemarks
SystemPathconst FString &Unreal object path of the existing NiagaraSystem.
DeleteJsonconst FString &JSON selecting type=renderer, user_parameter or disable_emitter. Renderer removal selects emitter and renderer_index/index; user_parameter removal requires name; disabling names an emitter.
bSaveAssetsboolWhether to save the modified system. The MCP tool default is save_assets=false.

Returns

JSON with success, system, operation, target identifiers, removed/changed and saved, or success=false/error for invalid operations or targets.

MCP Niagara Merge Write(SystemPath, PatchJson, bSaveAssets)

UMassBattleNiagaraMCPApi::MCP_NiagaraMergeWrite

Union-merge Niagara property writes. This does not delete.

Description

MCP tool: niagara_merge_write. Resolves explicit system, emitter-data or renderer targets and union-merges requested reflected property values. Omitted properties are retained. Each result records target resolution and before/after values; saving is optional.

Inputs

NameTypeRemarks
SystemPathconst FString &Unreal object path of the existing NiagaraSystem.
PatchJsonconst FString &JSON containing patches, or one patch object. Each patch selects a target, property/path and value_text or value. Use real reflected property names from read_all.
bSaveAssetsboolWhether to save the modified system. The MCP tool default is save_assets=false.

Returns

JSON with success, system, saved and per-patch results including target_resolved, before and after. Invalid targets/properties/values or save failures report actual errors.

MCP Niagara Read Graph(SystemPath, SelectorJson)

UMassBattleNiagaraMCPApi::MCP_NiagaraReadGraph

Read Niagara script graphs with stable node/pin ids and explicit links.

Description

MCP tool: niagara_read_graph. Reads system or standalone NiagaraScript graphs and returns stable node/pin identifiers and explicit links. Optional stack-input topology and compile-state reports provide the identities and diagnostics used by the graph-edit tool.

Inputs

NameTypeRemarks
SystemPathconst FString &Unreal object path of a NiagaraSystem or supported NiagaraScript asset.
SelectorJsonconst FString &JSON object; pass {} to use the defaults. include_nodes, include_pins, include_stack_inputs and include_compile_state select returned detail; max_nodes bounds exported graph nodes. Graph selection fields choose the relevant script/emitter scope.

Returns

MCP Niagara Set Module Pin(SystemPath, SelectorJson, PinName, ValueText, bSaveAssets)

UMassBattleNiagaraMCPApi::MCP_NiagaraSetModulePin

Set one Niagara function-call module input pin default value.

Description

MCP tool: niagara_set_module_pin. Resolves one function-call module and named pin, then writes its default value. Linked pins require allow_linked=true because the default may be ignored; non-input pins require allow_output=true. The report identifies the selected node and old/new text.

Inputs

NameTypeRemarks
SystemPathconst FString &Unreal object path of the existing NiagaraSystem.
SelectorJsonconst FString &JSON using emitter, module/function_name, node_guid or module_index; allow_linked and allow_output opt into the corresponding writes.
PinNameconst FString &Exact pin name returned by module inspection.
ValueTextconst FString &Default value in the selected pin type text/import syntax.
bSaveAssetsboolWhether to save the modified system. The MCP tool default is save_assets=true.

Returns

JSON with system, module_index, emitter, module, pin, linked_to_count, before, after and saved. Unresolved or ambiguous targets and refused pins return success=false/error.
