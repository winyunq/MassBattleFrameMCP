MCP Style Plan Organize Units

UMassBattleStyleMCPApi::MCP_StylePlanOrganizeUnits

Calculate destination folders and a move list from unit styles.

Description

Calculates destination folders from each unit style family and style index. It produces a reviewable move list only; this entry does not execute AssetTools moves.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. target_root selects the organization root; unit scan options select the source assets.

Returns

A move proposal containing source and destination paths under target_root; dry_run_only=true identifies it as a plan rather than executed moves.

MCP Style Summarize Units

UMassBattleStyleMCPApi::MCP_StyleSummarizeUnits

Count units by style family, style index and path category.

Description

Scans the selected unit assets and aggregates their authored style indices, inferred style families and path categories. It reports organization counts without moving assets.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. Use the unit scan options to choose the assets included in the summary.

Returns

The unit count and distributions across style families, path categories and style indices.

MCP Unit Apply Plan

UMassBattleUnitMCPApi::MCP_UnitApplyPlan

Write the changes recorded in a reviewed unit plan.

Inspect the diff with MCP Unit Preview Diff before submitting a reviewed plan.

Description

Loads the stored plan, rejects a plan marked inapplicable, and executes its supported mutation type. The result records applied changes and the requested persistence behavior.

Inputs

NameTypeRemarks
PlanIdconst FString &Identifier of the reviewed stored unit mutation plan.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

The executed plan's ID, applied_diff and saved state; rejected plans, failed mutations and save errors report their failure.

Function

MCP Unit Create

UMassBattleUnitMCPApi::MCP_UnitCreate

Use a template to create unit data or a Unit Source Actor.

Description

Creates a unit from the default or explicit template and optionally merges initial authored data. asset_type=source_actor creates a Unit Source Actor Blueprint; the ordinary branch creates the unit config. Target names must resolve to an unoccupied Unreal asset path.

Inputs

NameTypeRemarks
CreateSpecJsonconst FString &JSON with either unit_path/new_unit_path or both asset_name and package_path. template_unit selects a template; unit_data supplies initial authored values. asset_type=source_actor enables the source Blueprint branch and export_path configures its output.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

The created asset's identity and persistence result; failures explain destination conflicts or initial-data merge problems.

Function

MCP Unit Delete

UMassBattleUnitMCPApi::MCP_UnitDelete

Preview or execute a unit asset deletion plan.

Description

Builds the explicit unit deletion plan. dry_run=true returns would_delete and the plan without changing the asset; dry_run=false applies an applicable plan through the same mutation API.

Inputs

NameTypeRemarks
UnitPathconst FString &Unreal object path of the existing MassBattle unit config or supported Unit Source Actor Blueprint.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. dry_run defaults to true. Deletion mode and plan validation are handled by the explicit unit deletion plan.

Returns

A deletion preview with would_delete, or the actual deletion result; dry_run distinguishes the two and applicable explains whether the plan can execute.

MCP Unit Export

UMassBattleUnitMCPApi::MCP_UnitExport

Produce JSON or CSV balance data for comparison and tuning.

Description

Reads the selected unit balance fields and writes a JSON or CSV table. With no output_path, files are placed under the project Saved/MassBattleEditorMCP/Exports directory. The response identifies the created file and exported unit count.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. format chooses JSON or CSV; output_path selects the destination file. Unit scan and field options choose table contents.

Returns

The exported file's output_path, format and unit_count; failures identify invalid options or a file that could not be saved.

MCP Unit Get

UMassBattleUnitMCPApi::MCP_UnitGet

Inspect authored unit data and source Actor export information.

Description

Loads the requested unit or Unit Source Actor and returns source-aligned authored Data. The default simple view omits runtime, system and deprecated fields; a source Actor response also identifies export_path, exported_unit and last_report.

Inputs

NameTypeRemarks
UnitPathconst FString &Unreal object path of the existing MassBattle unit config or supported Unit Source Actor Blueprint.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. Select the requested detail/object view and field inclusion policy; the response reports detail and default_ignore_policy.

Returns

The unit's identity and authored configuration in Data, with detail identifying the selected field view.

MCP Unit Get Schema

UMassBattleUnitMCPApi::MCP_UnitGetSchema

Identify field names, types and nested structures accepted by unit patches.

Description

Builds the editable property schema of UMassBattleAgentConfigDataAsset and applies the same default field-ignore policy as unit reads. Recursive mode expands nested struct fields so a caller can build a patch from real property names.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. recursive defaults to true; depth defaults to 3 in recursive mode and 0 otherwise, and is clamped to 0..8.

Returns

The supported unit class and editable field definitions, including their types, nested structure and default field filtering policy.

Function

MCP Unit List

UMassBattleUnitMCPApi::MCP_UnitList

Find unit assets and their balance values by path.

Description

Scans unit config assets, filters their object paths by query, and returns compact balance summaries. load_fields controls whether assets are loaded for authored values. The returned total_scanned counts candidates before the query and result limit.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. query is case-insensitive path text; limit is clamped to 1..2000; load_fields defaults to true.

Returns

Unit summaries and search metadata; count is the returned item count, while total_scanned counts candidates before filtering and limiting.

Function

MCP Unit Merge Update

UMassBattleUnitMCPApi::MCP_UnitMergeUpdate

Change selected unit fields while retaining unspecified data.

Description

Plans a union-merge, checks success and applicable, then applies the returned plan automatically. It retains omitted fields and returns the planning result when validation blocks application.

Inputs

NameTypeRemarks
UnitPathconst FString &Unreal object path of the existing MassBattle unit config or supported Unit Source Actor Blueprint.
UnitDataJsonconst FString &Partial source-aligned authored unit data. Obtain exact editable field names from the unit schema.
bSaveAssetsboolWhether to save the assets modified or created by this operation to disk.

Returns

The applied field changes and persistence result, or the planning result when the proposed update cannot be applied.

See also

MCP Unit Get Schema for editable fields.

Function

MCP Unit Plan Merge Update

UMassBattleUnitMCPApi::MCP_UnitPlanMergeUpdate

Review field changes before writing a partial unit update.

Description

Builds and stores a union-merge plan from a partial source-aligned unit object. Omitted unit fields are retained. The asset is not modified; applicable and merge_errors describe whether the planned field changes can be applied.

Inputs

NameTypeRemarks
UnitPathconst FString &Unreal object path of the existing MassBattle unit config or supported Unit Source Actor Blueprint.
UnitDataJsonconst FString &Partial unit JSON using source property names. Include the fields to change; a Unit Source Actor patch may also contain export_path.

Returns

A stored update plan: plan_id identifies it for later review or application, diff describes field changes, and applicable with merge_errors explains whether it can run.

MCP Unit Preview Diff

UMassBattleUnitMCPApi::MCP_UnitPreviewDiff

Inspect a stored plan's full diff and applicability.

Obtain PlanId from a planning operation such as MCP Unit Plan Merge Update.

Description

Loads a previously stored mutation plan and returns its complete diff and applicability without applying it. This is the review step between planning and an explicit apply.

Inputs

NameTypeRemarks
PlanIdconst FString &plan_id returned by a unit planning operation.

Returns

The complete stored plan and its diff, with applicable indicating whether it is executable; an unavailable plan produces an error.
