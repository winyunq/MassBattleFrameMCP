UMassBattleStyleMCPApi::MCP_StylePlanOrganizeUnits

Plan unit folders by style.

Description

MCP tool: style_plan_organize_units. Calculates destination folders from each unit style family and style index. It produces a reviewable move list only; this entry does not execute AssetTools moves.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. target_root selects the organization root; unit scan options select the source assets.

Returns

JSON with success, plan_type, target_root, dry_run_only=true and moves containing source and destination paths.

UMassBattleStyleMCPApi::MCP_StyleSummarizeUnits

Summarize units by style.

Description

MCP tool: style_summarize_units. Scans the selected unit assets and aggregates their authored style indices, inferred style families and path categories. It reports organization counts without moving assets.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. Use the unit scan options to choose the assets included in the summary.

Returns

JSON with success, unit_count, style_families, path_categories and style_indices.

MCP Unit Apply Plan(PlanId, bSaveAssets)

UMassBattleUnitMCPApi::MCP_UnitApplyPlan

Apply a unit modification plan.

Inspect the diff with MCP Unit Preview Diff before submitting a reviewed plan.

Description

MCP tool: unit_apply_plan. Loads the stored plan, rejects a plan marked inapplicable, and executes its supported mutation type. The result records applied changes and the requested persistence behavior.

Inputs

NameTypeRemarks
PlanIdconst FString &Identifier of the reviewed stored unit mutation plan.
bSaveAssetsboolWhether to save the modified or newly created assets to disk. The MCP tool supplies its documented save_assets default; false leaves changes in editor memory.

Returns

JSON containing the mutation result, plan_id, saved and applied_diff, or success=false and error for an invalid plan, failed mutation or save failure.

MCP Unit Create(CreateSpecJson, bSaveAssets)

UMassBattleUnitMCPApi::MCP_UnitCreate

Create a unit from a template.

Description

MCP tool: unit_create. Creates a unit from the default or explicit template and optionally merges initial authored data. asset_type=source_actor creates a Unit Source Actor Blueprint; the ordinary branch creates the unit config. Target names must resolve to an unoccupied Unreal asset path.

Inputs

NameTypeRemarks
CreateSpecJsonconst FString &JSON with either unit_path/new_unit_path or both asset_name and package_path. template_unit selects a template; unit_data supplies initial authored values. asset_type=source_actor enables the source Blueprint branch and export_path configures its output.
bSaveAssetsboolWhether to save the modified or newly created assets to disk. The MCP tool supplies its documented save_assets default; false leaves changes in editor memory.

Returns

The create/apply JSON response identifying the created asset and saved state. Invalid target paths, occupied assets or initial-data merge errors return success=false and error.

Function

MCP Unit Delete(UnitPath, OptionsJson)

UMassBattleUnitMCPApi::MCP_UnitDelete

Delete a unit configuration asset.

Description

MCP tool: unit_delete. Builds the explicit unit deletion plan. dry_run=true returns would_delete and the plan without changing the asset; dry_run=false applies an applicable plan through the same mutation API.

Inputs

NameTypeRemarks
UnitPathconst FString &Unreal object path of the existing MassBattle unit config or supported Unit Source Actor Blueprint.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. dry_run defaults to true. Deletion mode and plan validation are handled by the explicit unit deletion plan.

Returns

A deletion plan with dry_run and would_delete, or the applied deletion result. Invalid JSON or an inapplicable plan reports success=false/error or applicable=false.

MCP Unit Export(OptionsJson)

UMassBattleUnitMCPApi::MCP_UnitExport

Export a unit balance table.

Description

MCP tool: unit_export. Reads the selected unit balance fields and writes a JSON or CSV table. With no output_path, files are placed under the project Saved/MassBattleEditorMCP/Exports directory. The response identifies the created file and exported unit count.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. format chooses JSON or CSV; output_path selects the destination file. Unit scan and field options choose table contents.

Returns

JSON with success, format, output_path and unit_count. Invalid options or a file-save failure returns success=false and error.

Find assets for unit authoring.

Description

MCP tool: unit_find_assets. Searches meshes, renderers, Niagara systems, AnimToTexture assets and existing unit configs, then sorts matches by object path for stable authoring discovery.

MCP Unit Get(UnitPath, OptionsJson)

UMassBattleUnitMCPApi::MCP_UnitGet

Read a unit configuration.

Description

MCP tool: unit_get. Loads the requested unit or Unit Source Actor and returns source-aligned authored Data. The default simple view omits runtime, system and deprecated fields; a source Actor response also identifies export_path, exported_unit and last_report.

Inputs

NameTypeRemarks
UnitPathconst FString &Unreal object path of the existing MassBattle unit config or supported Unit Source Actor Blueprint.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. Select the requested detail/object view and field inclusion policy; the response reports detail and default_ignore_policy.

Returns

JSON with success, AssetName, ObjectPath, Class, detail and Data. Invalid JSON or an unresolved unit returns success=false and error.

MCP Unit Get Schema(OptionsJson)

UMassBattleUnitMCPApi::MCP_UnitGetSchema

Read editable unit fields.

Description

MCP tool: unit_get_schema. Builds the editable property schema of UMassBattleAgentConfigDataAsset and applies the same default field-ignore policy as unit reads. Recursive mode expands nested struct fields so a caller can build a patch from real property names.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. recursive defaults to true; depth defaults to 3 in recursive mode and 0 otherwise, and is clamped to 0..8.

Returns

JSON with success, asset_class, fields and default_ignore_policy. Invalid JSON returns success=false and error.

MCP Unit List(OptionsJson)

UMassBattleUnitMCPApi::MCP_UnitList

List unit configuration assets.

Description

MCP tool: unit_list. Scans unit config assets, filters their object paths by query, and returns compact balance summaries. load_fields controls whether assets are loaded for authored values. The returned total_scanned counts candidates before the query and result limit.

Inputs

NameTypeRemarks
OptionsJsonconst FString &JSON object; pass {} to use the defaults. query is case-insensitive path text; limit is clamped to 1..2000; load_fields defaults to true.

Returns

JSON with success, count, total_scanned, units, roots and default_ignore_policy. Invalid JSON returns success=false with error.

MCP Unit Merge Update(UnitPath, UnitDataJson, bSaveAssets)

UMassBattleUnitMCPApi::MCP_UnitMergeUpdate

Update selected unit fields.

Description

MCP tool: unit_write. Plans a union-merge, checks success and applicable, then applies the returned plan automatically. It retains omitted fields and returns the planning result when validation blocks application.

Inputs

NameTypeRemarks
UnitPathconst FString &Unreal object path of the existing MassBattle unit config or supported Unit Source Actor Blueprint.
UnitDataJsonconst FString &Partial source-aligned authored unit data. Obtain exact editable field names from the unit schema.
bSaveAssetsboolWhether to save the modified or newly created assets to disk. The MCP tool supplies its documented save_assets default; false leaves changes in editor memory.

Returns

The planning error or the apply response, including success, saved and applied_diff.

See also

MCP Unit Get Schema for editable fields.

MCP Unit Plan Merge Update(UnitPath, UnitDataJson)

UMassBattleUnitMCPApi::MCP_UnitPlanMergeUpdate

Preview unit configuration changes.

Description

MCP tool: unit_plan_write. Builds and stores a union-merge plan from a partial source-aligned unit object. Omitted unit fields are retained. The asset is not modified; applicable and merge_errors describe whether the planned field changes can be applied.

Inputs

NameTypeRemarks
UnitPathconst FString &Unreal object path of the existing MassBattle unit config or supported Unit Source Actor Blueprint.
UnitDataJsonconst FString &Partial unit JSON using source property names. Include the fields to change; a Unit Source Actor patch may also contain export_path.

Returns

JSON with plan_id, plan_path, merge_semantics, patches, diff, merge_errors and applicable. Invalid JSON, an unresolved asset or no mergeable fields returns success=false and error.

MCP Unit Preview Diff(PlanId)

UMassBattleUnitMCPApi::MCP_UnitPreviewDiff

Read a unit plan and its changes.

Obtain PlanId from a planning operation such as MCP Unit Plan Merge Update.

Description

MCP tool: unit_preview_plan. Loads a previously stored mutation plan and returns its complete diff and applicability without applying it. This is the review step between planning and an explicit apply.

Inputs

NameTypeRemarks
PlanIdconst FString &plan_id returned by a unit planning operation.

Returns

JSON with success, plan_id, type, applicable, diff/diff_from_template and the complete plan. A missing or unreadable plan returns success=false and error.
