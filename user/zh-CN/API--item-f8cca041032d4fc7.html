MassBattleNiagaraMCPApi.h

将 Niagara 特效接入 MassBattle 批处理。

以 UE 5.8 的 Niagara 编辑器能力为完整功能基线，读取系统、发射器、渲染器、模块引脚和脚本图，再通过显式属性写入、堆栈输入与图编辑把现有效果接入 MassBattle 批处理。 改造过程使用源系统与目标系统的语义比较、图连接证据和编译诊断检查保留结果；写入和删除分别使用各自的公开工具。各函数说明其选择器、操作 JSON、保存行为及返回报告。

类

UMassBattleNiagaraMCPApi

检查和编辑 Niagara 系统。

提供类似资产与图命令行工具的基础操作：查询、读取、文本导出、合并写入及显式删除。

UMassBattleNiagaraMCPApi::MCP_NiagaraAddSpriteRenderer

添加 Niagara 精灵渲染器。

描述

MCP 工具：niagara_add_sprite_renderer。在现有发射器上创建精灵渲染器，配置材质、用户参数绑定、排序和可见性。添加过程保留现有发射器图，随后执行收尾编译及可选保存。

输入

名称类型说明
Niagara 系统路径SystemPathconst FString &现有 NiagaraSystem 资产的 Unreal 对象路径。
发射器名称EmitterNameconst FString &接收新渲染器的现有发射器名称。
渲染器配置 JSONRendererJsonconst FString &JSON 包含 material，以及可选的 material_user_parameter、enabled_user_parameter、sort_order 和 renderer_visibility。
保存资产bSaveAssetsbool是否保存修改后的系统。MCP 工具默认 save_assets=false。

返回值

渲染器添加与编译报告，包含新渲染器及 saved 状态。JSON 无效、发射器或材质无法解析、分配失败时返回 success=false/error。

UMassBattleNiagaraMCPApi::MCP_NiagaraApplyGraphEdit

编辑 Niagara 脚本图。

描述

MCP 工具：niagara_apply_graph_edit。校验有序操作记录及其标识，执行明确的图或堆栈编辑，统一编译一次，保存前检查源内容保留情况。操作包括复制发射器、用户值与数据接口、插入模块或赋值、连接或断开及重接引脚、编辑堆栈输入。空 operations 数组仅执行编译和校验。

输入

名称类型说明
Niagara 系统路径SystemPathconst FString &现有 NiagaraSystem 资产的 Unreal 对象路径。
编辑规格 JSONEditJsonconst FString &JSON 包含 operations 数组（别名 edits）。每项给出 op/type、可选的唯一 id，以及操作和源内容保留规则所需的字段。
保存资产bSaveAssetsbool是否保存修改后的系统。MCP 工具默认 save_assets=false。

返回值

有序操作、编译及保留校验报告，包含实际编辑结果和 saved 状态。操作格式错误、编辑失败或校验失败时报告对应错误。

UMassBattleNiagaraMCPApi::MCP_NiagaraCompareSystems

比较两个 Niagara 系统。

描述

MCP 工具：niagara_compare_systems。加载两个不同系统并比较语义指纹。exact 模式检查复制结果；translation 模式按配置的保留规则检查改造结果。编译可运行状态、错误和警告选项控制相应检查。

输入

名称类型说明
源系统路径SourceSystemPathconst FString &参考 NiagaraSystem 的 Unreal 对象路径。
目标系统路径TargetSystemPathconst FString &待比较的另一 NiagaraSystem 的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。mode 为 exact 或 translation；require_ready_to_run、require_no_compile_errors、require_no_warnings 选择编译状态要求。

返回值

比较报告 JSON，包含保留检查、源和目标发射器及渲染器数量、unexpected_removed_edges 和可运行状态。输入无效或源与目标为同一资产时返回 success=false/error。

UMassBattleNiagaraMCPApi::MCP_NiagaraReadGraph

读取 Niagara 脚本图及其连接。

描述

MCP 工具：niagara_read_graph。读取系统或独立 NiagaraScript 的图，返回稳定节点、引脚标识和显式连线。可选的堆栈输入拓扑和编译状态报告，为图编辑提供目标标识与诊断信息。

输入

名称类型说明
Niagara 系统路径SystemPathconst FString &NiagaraSystem 或受支持 NiagaraScript 资产的 Unreal 对象路径。
选择器 JSONSelectorJsonconst FString &JSON 对象；{} 使用默认选项。include_nodes、include_pins、include_stack_inputs、include_compile_state 选择详细信息；max_nodes 限制导出的节点数。图选择字段确定脚本或发射器范围。

返回值

JSON 包含 graph_count、graphs 和已解析的系统或脚本标识，并按选项附加 compile_state、堆栈输入可用信息。选择器或资产无效时返回 success=false/error。

MCP 工具：niagara_read_module。收集系统中的函数调用模块节点，返回首个符合发射器、模块、GUID 或索引筛选条件的记录。记录包含引脚信息，便于后续精确修改。

输入

名称类型说明
Niagara 系统路径SystemPathconst FString &现有 NiagaraSystem 资产的 Unreal 对象路径。
选择器 JSONSelectorJsonconst FString &JSON 对象，可包含 emitter、module/function_name、node_guid 和 module_index/index。使用 GUID 或已收集的模块索引定位具体节点。

返回值

JSON 包含 success 和 module。JSON 无效、系统无法解析或没有匹配模块时返回 success=false/error。

设置 Niagara 模块输入默认值。

引脚名称PinNameconst FString &模块检查返回的精确引脚名称。
值文本ValueTextconst FString &符合该引脚类型文本导入语法的默认值。

JSON 包含 system、module_index、emitter、module、pin、linked_to_count、before、after 和 saved。目标无法解析、不唯一或引脚写入被拒绝时返回 success=false/error。
