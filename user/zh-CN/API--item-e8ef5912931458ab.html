类

UMassBattleProjectileMCPApi

维护投射物的移动、伤害、触发和生命周期特效配置。

此 API 编辑投射物玩法资产。关联的一次性和附着视觉效果属于 MassBattle 批处理特效与 Niagara 创作，由特效 API 处理。

函数

创建投射物配置

UMassBattleProjectileMCPApi::MCP_ProjectileCreate

从模板或类默认值生成通过校验的投射物配置。

描述

从指定模板或类默认值创建临时预览，应用初始源码对应数据并完成校验后，再创建真实数据资产。目标无效或已被占用时拒绝创建，不替换已有资产。

输入

名称类型说明
创建规格 JSONCreateSpecJsonconst FString &JSON 包含 asset_name（别名 name）、package_path（别名 target_package_path），以及可选 template_path/template 和初始投射物数据。package_path 须为以 / 开头的 Unreal 包路径。
保存资产bSaveAssetsbool= true是否将本次修改或创建的资产保存到磁盘。

返回值

新资产与模板路径、生成后的配置和写入字段路径；saved 说明资产是否已保存到磁盘。

函数

规划或删除投射物配置

UMassBattleProjectileMCPApi::MCP_ProjectileDelete

检查引用关系后预览或执行资产移除。

描述

生成删除或移入回收目录的报告并检查引用。dry_run=true 只返回报告；显式执行请求按支持的模式操作，并报告实际移动或删除结果。

输入

名称类型说明
投射物路径ProjectilePathconst FString &待删除投射物配置的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。dry_run 默认为 true，mode 选择删除方式，trash_root 指定回收目录。涉及引用、不安全移动或硬删除时，需要对应的 allow_referenced、allow_unsafe_asset_move 或 allow_hard_delete 选项。

返回值

删除或回收报告，列明引用关系、可执行状态及阻塞原因；执行后附实际回收路径或删除数量。

函数

读取投射物配置

UMassBattleProjectileMCPApi::MCP_ProjectileGet

查看当前生效的投射物配置及可选的校验、引用信息。

描述

加载投射物数据资产并返回与源码字段对应的创作数据。有效字段视图按移动和伤害模式筛选字段，完整视图可包含非当前模式字段；同次读取也可附加校验和引用方报告。

输入

名称类型说明
投射物路径ProjectilePathconst FString &投射物配置数据资产的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。view/detail 和 include_inactive 选择字段视图；include_validation、include_referencers 请求相应报告。

返回值

data 中的投射物配置及其移动、伤害模式；view 标明字段视图，并按选项附带校验报告和引用资产。

函数

列出投射物工具能力

UMassBattleProjectileMCPApi::MCP_ProjectileGetApiStatus

确认当前编辑器的投射物读写与校验操作。

描述

返回投射物数据资产的工具能力、原生参数名称和写入约定，说明当前编辑器提供的字段结构、增删改查及校验入口。

返回值

投射物 API 的版本、支持的资产类型、写入约定和可用工具。

函数

读取投射物字段结构

UMassBattleProjectileMCPApi::MCP_ProjectileGetSchema

获取各移动、伤害模式的字段类型和写入规则。

描述

反射投射物的字段名、类型、枚举、编辑条件和提示，返回移动、伤害模式字段组，以及写入、伤害归属和生命周期规则。数组默认按索引合并且不允许追加；options.append_arrays=true 允许追加，options.array_mode=replace 显式替换。普通投射物攻击由投射物数据资产负责伤害，攻击者使用 Agent Attack.TimeOfHitAction=None；生命周期规则指出 OnHit、OnRemoval 重复执行完整爆炸的问题。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。depth 控制嵌套字段结构的展开深度。

返回值

字段定义及按移动、伤害模式划分的字段组，并附数组写入、伤害归属和生命周期规则。

函数

列出投射物配置

UMassBattleProjectileMCPApi::MCP_ProjectileList

按路径筛选投射物资产并查看配置摘要。

描述

扫描投射物配置数据资产，按 query 筛选对象路径并返回稳定的资产摘要。load_fields 控制是否加载每项资产的创作字段。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。query 筛选路径，limit 限制返回数量，load_fields 控制摘要详细程度；扫描根目录决定内容范围。

返回值

匹配的投射物摘要及搜索目录；count 是本次返回条数，total_scanned 是扫描数量。

查询投射物配置

UMassBattleProjectileMCPApi::MCP_ProjectileQuery

通过名称或路径定位投射物配置资产。

描述

复用投射物列表查询入口，按路径或名称查找配置，返回相同的稳定摘要和扫描元数据。

输入

名称类型说明
查询 JSONQueryJsonconst FString &JSON 对象；{} 使用默认选项。采用投射物列表的查询和范围选项。

返回值

与 projectile_list 同格式的搜索结果，包含匹配资产、返回与扫描数量及搜索目录。

函数

校验投射物配置

UMassBattleProjectileMCPApi::MCP_ProjectileValidate

检查移动、伤害归属和生命周期特效的配置问题。

描述

检查目标投射物的移动配置、伤害归属、触发与寿命行为、生命周期特效及重复爆炸风险；本入口不修改配置。

输入

名称类型说明
投射物路径ProjectilePathconst FString &待检查投射物数据资产的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。include_referencers 附加引用该投射物的资产。

返回值

validation 中的投射物校验结论与问题清单，并按选项附带引用资产。

函数

合并写入投射物配置

UMassBattleProjectileMCPApi::MCP_ProjectileWrite

校验局部改动后写入，保留未指定的投射物字段。

描述

先在临时副本上应用局部补丁并校验，再修改真实配置。未指定字段保留；修改数组或嵌套创作结构时遵循字段结构中的写入规则。

输入

名称类型说明
投射物路径ProjectilePathconst FString &现有投射物数据资产的 Unreal 对象路径。
补丁 JSONPatchJsonconst FString &使用真实源码字段名的非空局部投射物 JSON。枚举、条件和数组规则见投射物字段结构；options.append_arrays、options.array_mode 显式选择追加或替换。
保存资产bSaveAssetsbool= true是否将本次修改或创建的资产保存到磁盘。

返回值

实际更新的字段路径、更新后的配置及校验报告；saved 说明是否已保存，失败时报告字段、预校验或保存错误。
