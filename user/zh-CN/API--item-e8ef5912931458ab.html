UMassBattleProjectileMCPApi

读写投射物配置。

此 API 编辑投射物玩法资产。关联的一次性和附着视觉效果属于 MassBattle 批处理特效与 Niagara 创作，由特效 API 处理。

创建投射物配置(创建规格 JSON, 保存资产)

UMassBattleProjectileMCPApi::MCP_ProjectileCreate

创建投射物配置。

描述

MCP 工具：projectile_create。从指定模板或类默认值创建临时预览，应用初始源码对应数据并完成校验后，再创建真实数据资产。目标无效或已被占用时拒绝创建，不替换已有资产。

输入

名称类型说明
创建规格 JSONCreateSpecJsonconst FString &JSON 包含 asset_name（别名 name）、package_path（别名 target_package_path），以及可选 template_path/template 和初始投射物数据。package_path 须为以 / 开头的 Unreal 包路径。
保存资产bSaveAssetsbool= true是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值

JSON 包含 success、asset_path、template_path、saved、changed_paths 和 data。输入、预检查或创建失败时返回 success=false/error。

规划或删除投射物配置(投射物路径, 选项 JSON)

UMassBattleProjectileMCPApi::MCP_ProjectileDelete

删除投射物配置。

描述

MCP 工具：projectile_delete。生成删除或移入回收目录的报告并检查引用。dry_run=true 只返回报告；显式执行请求按支持的模式操作，并报告实际移动或删除结果。

输入

名称类型说明
投射物路径ProjectilePathconst FString &待删除投射物配置的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。dry_run 默认为 true，mode 选择删除方式，trash_root 指定回收目录。涉及引用、不安全移动或硬删除时，需要对应的 allow_referenced、allow_unsafe_asset_move 或 allow_hard_delete 选项。

返回值

JSON 包含 dry_run、mode、source_path、referencers、applicable 和 blocked_reason；执行后增加 moved/trash_path 或 deleted/deleted_count，以及实际错误。

读取投射物配置(投射物路径, 选项 JSON)

UMassBattleProjectileMCPApi::MCP_ProjectileGet

读取投射物配置。

描述

MCP 工具：projectile_get。加载投射物数据资产并返回与源码字段对应的创作数据。有效字段视图按移动和伤害模式筛选字段，完整视图可包含非当前模式字段；同次读取也可附加校验和引用方报告。

输入

名称类型说明
投射物路径ProjectilePathconst FString &投射物配置数据资产的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。view/detail 和 include_inactive 选择字段视图；include_validation、include_referencers 请求相应报告。

返回值

JSON 包含 success、asset_name、object_path、class、view、movement_mode、damage_mode 和 data，以及按请求返回的 validation/referencers。

函数

列出投射物工具能力()

UMassBattleProjectileMCPApi::MCP_ProjectileGetApiStatus

列出可用的投射物工具。

描述

MCP 工具：projectile_get_api_status。返回投射物数据资产的工具能力、原生参数名称和写入约定，说明当前编辑器提供的字段结构、增删改查及校验入口。

返回值

JSON 包含 success、api_name、version、asset_class、write_contract 和 tools。

函数

读取投射物字段结构(选项 JSON)

UMassBattleProjectileMCPApi::MCP_ProjectileGetSchema

读取投射物的可编辑字段。

描述

MCP 工具：projectile_get_schema。反射投射物的字段名、类型、枚举、编辑条件和提示，返回移动、伤害模式字段组，以及写入、伤害归属和生命周期规则。数组默认按索引合并且不允许追加；options.append_arrays=true 允许追加，options.array_mode=replace 显式替换。普通投射物攻击由投射物数据资产负责伤害，攻击者使用 Agent Attack.TimeOfHitAction=None；生命周期规则指出 OnHit、OnRemoval 重复执行完整爆炸的问题。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。depth 控制嵌套字段结构的展开深度。

返回值

JSON 包含 success、class、field_count、fields、movement_mode_fields、damage_mode_fields、array_write_rule、damage_ownership_rule 和 lifecycle_rule。

列出投射物配置(选项 JSON)

UMassBattleProjectileMCPApi::MCP_ProjectileList

列出投射物配置。

描述

MCP 工具：projectile_list。扫描投射物配置数据资产，按 query 筛选对象路径并返回稳定的资产摘要。load_fields 控制是否加载每项资产的创作字段。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。query 筛选路径，limit 限制返回数量，load_fields 控制摘要详细程度；扫描根目录决定内容范围。

返回值

JSON 包含 success、count、total_scanned、roots 和 projectiles；选项无效时返回 success=false/error。

输入

UMassBattleProjectileMCPApi::MCP_ProjectileValidate

校验投射物配置。

描述

MCP 工具：projectile_validate。检查目标投射物的移动配置、伤害归属、触发与寿命行为、生命周期特效及重复爆炸风险；本入口不修改配置。

输入

名称类型说明
投射物路径ProjectilePathconst FString &待检查投射物数据资产的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。include_referencers 附加引用该投射物的资产。

返回值

JSON 包含 success、validation，以及按请求返回的 referencers。路径或选项无效时返回 success=false/error。

合并写入投射物配置(投射物路径, 补丁 JSON, 保存资产)

UMassBattleProjectileMCPApi::MCP_ProjectileWrite

更新指定的投射物字段。

描述

MCP 工具：projectile_write。先在临时副本上应用局部补丁并校验，再修改真实配置。未指定字段保留；修改数组或嵌套创作结构时遵循字段结构中的写入规则。

输入

名称类型说明
投射物路径ProjectilePathconst FString &现有投射物数据资产的 Unreal 对象路径。
补丁 JSONPatchJsonconst FString &使用真实源码字段名的非空局部投射物 JSON。枚举、条件和数组规则见投射物字段结构；options.append_arrays、options.array_mode 显式选择追加或替换。
保存资产bSaveAssetsbool= true是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值

JSON 包含 success、asset_path、saved、changed_paths、data 和 validation；字段无效、预检查或保存失败时返回 success=false/error。
