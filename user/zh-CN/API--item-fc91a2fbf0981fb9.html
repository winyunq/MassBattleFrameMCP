UMassBattleUnitEditorMCPApi

把骨骼网格体或 Actor 制作为 VAT 单位，并整理生成资产。

原 MassBattleEditor 模块提供可从蓝图调用的编辑工具，将外购资产转换为适配 MassBattle 的数据。本 API 将这些已有工具组合成可审阅的 MCP 编辑操作。

函数

生成或更新 VAT 单位

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnit

将骨骼动画烘焙成贴图，生成用静态网格播放动画的单位。

描述

先把骨骼网格转为带 LOD 的静态网格，并由父材质创建材质实例。按各 LOD 的骨骼或顶点模式采样动画，生成 VAT 贴图；把这些贴图、动画索引贴图和解码参数写入对应材质，使静态网格能够还原动画。渲染器绑定网格、Niagara 系统和子类型；单位写入 Visualize.RendererClass、AnimShared.AnimData 及实际烘焙采样率。新单位通过 创建单位配置 创建，再通过 规划单位合并写入 和 应用单位变更规划 写入配置。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &JSON 制作规格，包含 skeletal_mesh、unit_name、target_package_path、parent_material、source_renderer_class、niagara_system、vat_sample_rate，以及 animations 分类到 AnimSequence 的非空映射。target_unit 指向已有单位；新建时由 template_unit、target_unit_package_path 和 subtype 描述目标。dry_run/preview_only 选择预览，overwrite_existing 控制是否替换已有生成物。compact_response 控制结果详略：此原生入口默认为 false，MCP 封装默认为 true，JSON 中显式值优先。
保存资产bSaveAssetsbool是否将本次修改或创建的资产保存到磁盘。

返回值

执行时返回逐步骤制作结果或紧凑摘要，预览时返回方案与校验。校验问题见 validation.valid 和 validation.issues；执行中断时 execution_steps 保留已完成及失败的步骤。

说明

主入口自动执行校验；规划和校验工具仅用于可选的预先诊断。

函数

从 Actor 装配并生成 VAT 单位

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnitFromActor

将 Actor 组件及武器装配为可播放动画的 VAT 单位。

描述

将解析后的 Actor 组件和武器合并为兼容动画的骨骼网格体，再把该网格与 VAT 参数交给 生成或更新 VAT 单位 制作单位资源。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &JSON 对象，包含 actor_class、可选 component_overrides 和 VAT 制作设置。assembled_skeletal_mesh_path 指定装配输出；否则由 target_package_path 与 unit_name 确定，可用 assembled_skeletal_mesh_name 覆盖名称。overwrite_existing 控制替换，dry_run/preview_only 选择预览；compact_response 控制结果详略，MCP 封装默认为 true，JSON 中显式值优先。
保存资产bSaveAssetsbool是否将本次修改或创建的资产保存到磁盘。

返回值

预览时返回装配方案；执行时返回装配骨骼网格体、实际 VAT 参数和 vat_result 制作结果，失败时报告对应装配或 VAT 步骤的问题。

从选区生成 VAT 单位

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnitFromSelection

自动从选中资产解析参数并生成 VAT 单位。

描述

从选区解析网格、动画和输出设置，交给 生成或更新 VAT 单位 制作；结果同时保留实际采用的选区和制作参数。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &选区解析和 VAT 制作选项。selected_assets 可覆盖当前选区；compact_response 控制结果详略，MCP 封装默认为 true，JSON 中显式值优先。
保存资产bSaveAssetsbool是否将本次修改或创建的资产保存到磁盘。

返回值

实际采用的选区和生成参数，以及 apply_result 或 apply_summary 中的制作结果；失败时指出选区解析或生成问题。

描述

重新生成同一整理规划，默认因 dry_run=true 而只返回规划。dry_run=false 时执行符合条件的 AssetTools 移动，报告每项实际移动及失败。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。布局选项与整理规划入口相同；dry_run 默认为 true，也接受 preview_only。
保存资产bSaveAssetsbool是否将本次修改或创建的资产保存到磁盘。

返回值

预览时返回移动方案；执行时返回逐项结果及实际移动数量，失败报告仍保留已执行的移动情况。

检查 Actor 网格体装配

UMassBattleUnitEditorMCPApi::MCP_EditorInspectActorAssembly

核对组件材质和武器绑骨，判断装配能否完成。

描述

生成或解析待检查 Actor，评估参与装配的骨骼、静态组件、有效材质及武器绑定骨骼，报告能否装配。包围盒使用根骨架模型空间，不重新居中；本入口不写入生成资产。

输入

名称类型说明
Actor 路径ActorPathconst FString &Actor 蓝图或类的对象路径；提供后写入检查规格的 actor_class。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。可选 component_overrides 控制组件是否参与装配及组件专用创作覆盖。

返回值

Actor 装配报告，包含组件、材质、武器绑定、包围盒及问题；can_assemble 说明当前能否装配。

检查 VAT 动画烘焙结果

UMassBattleUnitEditorMCPApi::MCP_EditorInspectVatAnimation

核对蒙皮、帧运动、查找 UV 和动画配置。

描述

加载 VAT 数据及其骨骼、静态网格体，检查变形蒙皮权重、位置帧运动和查找 UV，并将烘焙动画路径与选定士兵动画配置比较。本入口报告证据，不烘焙或编辑资产。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &JSON 包含 vat_data_asset（或 anim_to_texture_data_asset）；skeletal_mesh、static_mesh 显式指定网格体。ground_tolerance_uu 指定地面检查容差，单位为 Unreal 单位。

返回值

VAT 动画检查报告，包含蒙皮权重、帧运动、动画资源与 UV 证据及发现的问题。

预览 VAT 单位生成规划

UMassBattleUnitEditorMCPApi::MCP_EditorPlanCreateVatUnit

在生成前检查源网格体、动画和输出布局。

描述

根据源网格、单位名称和目标布局确定输出路径；把配方默认配置、解析出的网格/动画/LOD 引用、显式 unit_patch 依次合并，形成拟写入的单位配置。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &JSON 对象，描述源 skeletal_mesh、unit_name、target_package_path，以及可选的 recipe_id/style_profile、动画搜索路径和 unit_patch。target_unit 指向已有单位；template_unit 和 target_unit_package_path 描述新单位。

返回值

解析后的输出布局、发现的输入资产及拟执行步骤；可执行状态和警告说明尚待解决的问题。

另请参阅

函数

预览 Actor 转 VAT 单位规划

UMassBattleUnitEditorMCPApi::MCP_EditorPlanCreateVatUnitFromActor

核对 Actor 装配方案和解析后的 VAT 生成参数。

描述

从 Actor 检查结果取得组件网格、材质和武器绑定信息，结合动画、采样率、LOD 设置与装配网格输出路径，生成 resolved_vat_spec。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &JSON 对象，以 actor_class 指定源 Actor，可用 component_overrides 替换组件和武器，并指定输出目录与名称。VAT 字段定义见 生成或更新 VAT 单位；动画、采样率和 LOD 取值由 Actor 与传入设置共同解析。

返回值

resolved_vat_spec 中的实际 VAT 参数、拟生成的装配网格体及动画、采样率和 LOD 取值；applicable 与 issues 说明方案能否执行。

函数

从选区预览 VAT 单位规划

UMassBattleUnitEditorMCPApi::MCP_EditorPlanCreateVatUnitFromSelection

检查所选资产解析出的 VAT 生成参数。

描述

将编辑器选区或 selected_assets 解析为源网格和动画集合，再组成制作规格交给 预览 VAT 单位生成规划。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。selected_assets 提供显式选区；其他生成选项参与选区解析，并体现在 resolved_spec 中。

返回值

实际采用的选区、解析出的 VAT 参数和生成方案；ready_to_apply 说明该请求是否已具备执行条件。

规划单位关联资产整理

UMassBattleUnitEditorMCPApi::MCP_EditorPlanOrganizeUnitAssets

查看单位及其关联资产将被移动到哪些目录。

描述

解析风格布局，按整理策略发现单位及关联生成、源资产，计算源路径、目标路径和冲突状态；本入口不移动或保存资产。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。style_profile 选择默认布局，target_root 或 target_package_path 指定目标；unit_name、use_family_folder、generated_folder_name/target_folder_name、managed_roots 定制已有布局策略。

返回值

资产移动清单，逐项给出源路径、目标路径和检查状态，并附解析后的风格目录布局。

函数

校验 VAT 单位生成输入

UMassBattleUnitEditorMCPApi::MCP_EditorValidateCreateVatUnit

检查 VAT 所需字段和引用资产是否齐备。

描述

解析骨骼网格、父材质、渲染器和 Niagara 资源引用，检查动画分类映射及 VAT 制作设置，把发现的问题与拟执行步骤汇总为校验结果。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &VAT 制作规格，字段定义见 生成或更新 VAT 单位。检查网格、动画、材质、渲染器、输出位置和子类型配置，不生成资产。

返回值

valid 给出是否通过校验，issues 列出字段问题，execution_preview 给出拟执行流程。
