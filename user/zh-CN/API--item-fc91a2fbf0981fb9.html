函数

生成或更新 VAT 单位

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnit

按指定参数生成 VAT 单位。

描述

MCP 工具：editor_apply_create_vat_unit。完整规范输入通过校验后，执行与 MassBattleTools DoAll 等价的骨骼网格体 VAT 流程，经 MassBattleEditor 创建或更新 VAT 数据、材质、渲染器和单位。dry_run/preview_only 返回校验和执行预览；compact_response 在 MCP 工具中默认为 true，spec 中显式值优先。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &完整规范 VAT 生成 JSON：skeletal_mesh、unit_name、target_package_path、parent_material、source_renderer_class、niagara_system、vat_sample_rate 和非空 animations 分类到 AnimSequence 映射。更新时给出 target_unit；新建时给出 template_unit、target_unit_package_path、subtype。严格执行不接受旧别名及缺失资产或静态回退开关。dry_run/preview_only 控制预览，overwrite_existing 控制已有输出，compact_response 选择精简结果。
保存资产bSaveAssetsbool是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值

JSON 包含 success、dry_run、save_assets 和 execution_steps，或精简应用摘要。校验失败给出 valid=false、issues、execution_preview；步骤失败返回实际执行结果。

说明

主入口自动执行校验；规划和校验工具仅用于可选的预先诊断。

函数

从 Actor 装配并生成 VAT 单位

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnitFromActor

将 Actor 装配为 VAT 单位。

描述

MCP 工具：editor_apply_create_vat_unit_from_actor。生成并校验 Actor 装配规划，创建兼容动画的装配 SkeletalMesh，再将解析后的规范规格交给主 VAT 入口。dry_run/preview_only 只返回规划；compact_response 在 MCP 工具中默认为 true，可在 spec 中覆盖。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &JSON 包含 actor_class、可选 component_overrides 及规范 VAT 字段。assembled_skeletal_mesh_path 显式选择输出；否则由 target_package_path、unit_name 生成 SKM_<unit_name>_Assembled，可用 assembled_skeletal_mesh_name 改名。overwrite_existing 控制替换装配输出；VAT 输入与 Actor 规划入口相同，另支持 dry_run/preview_only 和 compact_response。
保存资产bSaveAssetsbool是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值

JSON 包含规划或装配结果、skeletal_mesh、resolved_vat_spec 和 vat_result。规划不可执行或装配、VAT 步骤失败时返回实际错误。

从选区生成 VAT 单位

UMassBattleUnitEditorMCPApi::MCP_EditorApplyCreateVatUnitFromSelection

从所选资产生成 VAT 单位。

描述

MCP 工具：editor_apply_create_vat_unit_from_selection。从当前选区或 selected_assets 构建规范 VAT 规格，执行同一主 DoAll 生成流程。compact_response 在 MCP 工具中默认为 true，显式选项优先；响应保留选区和解析后的输入。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。selected_assets 覆盖编辑器选区；生成选项和 compact_response 传给解析后的 VAT 流程。
保存资产bSaveAssetsbool是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值

JSON 包含 success、selection、resolved_spec 及 apply_result 或 apply_summary；选区解析或生成失败时返回对应错误。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。布局选项与整理规划入口相同；dry_run 默认为 true，也接受 preview_only。
保存资产bSaveAssetsbool是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值

JSON 包含 dry_run、plan、execution_steps、moved_count 和 moved；执行失败给出 success=false/error 及实际移动报告。

函数

检查 VAT 动画烘焙结果

UMassBattleUnitEditorMCPApi::MCP_EditorInspectVatAnimation

检查 VAT 动画烘焙结果。

描述

MCP 工具：editor_inspect_vat_animation。加载 VAT 数据及其骨骼、静态网格体，检查变形蒙皮权重、位置帧运动和查找 UV，并将烘焙动画路径与选定士兵动画配置比较。本入口报告证据，不烘焙或编辑资产。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &JSON 包含 vat_data_asset（或 anim_to_texture_data_asset）；skeletal_mesh、static_mesh 显式指定网格体。ground_tolerance_uu 指定地面检查容差，单位为 Unreal 单位。

返回值

VAT 动画检查 JSON，包含有效性、变形权重和运动结论、动画证据及网格体、UV 问题。JSON 无效或输入无法解析时返回 success=false 和 error。

函数

预览 VAT 单位生成规划

UMassBattleUnitEditorMCPApi::MCP_EditorPlanCreateVatUnit

预览 VAT 单位生成方案。

描述

MCP 工具：editor_plan_create_vat_unit。解析源网格体、配方和风格配置、动画与纹理发现结果、生成资产布局，保留生成资产原状。此入口用于诊断预览；发现别名或推断值不能替代严格执行需要的完整规范字段。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &JSON 描述 skeletal_mesh、unit_name、搜索路径、可选 recipe_id/style_profile 和预期生成布局。规范字段为 skeletal_mesh、unit_name、target_package_path、parent_material、source_renderer_class、niagara_system、vat_sample_rate，以及非空的 animations 分类到 AnimSequence 映射。更新单位时提供 target_unit；新建时提供 template_unit、target_unit_package_path 和 subtype。严格执行不接受旧别名及缺失资产或静态回退开关。

返回值

规划 JSON 包含 resolved_layout、discovery、可应用状态、warnings 和拟执行步骤；输入或配置解析失败时返回 success=false 和 error。

函数

预览 Actor 转 VAT 单位规划

UMassBattleUnitEditorMCPApi::MCP_EditorPlanCreateVatUnitFromActor

预览 Actor 的 VAT 单位生成方案。

描述

MCP 工具：editor_plan_create_vat_unit_from_actor。检查 Actor 装配，解析动画、采样率和 LOD 默认值，校验必需 VAT 字段及装配输出，再返回规范 resolved_vat_spec。报告路径冲突和装配问题，不创建生成资产。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &JSON 包含 actor_class、可选 component_overrides 及规范 VAT 字段。assembled_skeletal_mesh_path 显式指定装配资产；否则由 target_package_path、unit_name 生成 SKM_<unit_name>_Assembled，名称可用 assembled_skeletal_mesh_name 覆盖。overwrite_existing 控制替换已有装配输出。VAT 必需字段为 unit_name、target_package_path、parent_material、source_renderer_class、niagara_system、正数 vat_sample_rate、animations，以及 target_unit，或 template_unit/target_unit_package_path/subtype。

返回值

JSON 包含 applicable、assembled_skeletal_mesh、assembly_status、inspection、animation_resolution、vat_sample_rate_resolution、vat_lod_resolution、resolved_vat_spec 和 issues。

UMassBattleUnitEditorMCPApi::MCP_EditorPlanCreateVatUnitFromSelection

预览所选资产的 VAT 单位生成方案。

描述

MCP 工具：editor_plan_create_vat_unit_from_selection。将当前选中资产或 selected_assets 覆盖列表解析为 VAT 创建规格，并返回诊断规划，公开解析后的输入供审阅，不生成资产。

输入

名称类型说明

函数

规划单位关联资产整理

UMassBattleUnitEditorMCPApi::MCP_EditorPlanOrganizeUnitAssets

预览单位资产的目录整理方案。

描述

MCP 工具：editor_plan_organize_unit_assets。解析风格布局，按整理策略发现单位及关联生成、源资产，计算源路径、目标路径和冲突状态；本入口不移动或保存资产。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。style_profile 选择默认布局，target_root 或 target_package_path 指定目标；unit_name、use_family_folder、generated_folder_name/target_folder_name、managed_roots 定制已有布局策略。

返回值

供审阅的整理规划，包含 moves、源和目标路径、解析布局及逐项状态；失败时返回 success=false 和 error。

校验 VAT 单位生成输入

UMassBattleUnitEditorMCPApi::MCP_EditorValidateCreateVatUnit

校验 VAT 单位生成参数。

描述

MCP 工具：editor_validate_create_vat_unit。检查严格规范的 VAT 输入，解析引用资产并生成诊断执行预览，报告字段级问题；本入口不创建、烘焙或保存资产。

输入

名称类型说明
创作规格 JSONSpecJsonconst FString &完整的规范 VAT 生成 JSON。字段为 skeletal_mesh、unit_name、target_package_path、parent_material、source_renderer_class、niagara_system、vat_sample_rate，以及非空 animations 分类到 AnimSequence 映射。更新时提供 target_unit；新建时提供 template_unit、target_unit_package_path、subtype。严格执行不接受旧别名和缺失资产或静态回退开关。

返回值
