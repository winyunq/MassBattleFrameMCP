MassBattleFrame MCP/产品 API

产品 API

用于特效资产检查、管理和批处理渲染配置的 MCP 接口。

查询并识别 Niagara、Cascade、材质和蓝图等特效资产，读取类型化摘要或确定性文本，再执行复制、未保存副本回滚或显式删除。渲染器接口读写 MassBattle FX 渲染器类默认值，包括 Niagara 系统、Burst 数据通道、特效子类型和批量大小。 调用者从查询和检查结果取得真实资产路径与配置，再选择对应的资产操作或渲染配置工具。参数、默认行为和 JSON 返回结果在各公开函数中说明。

用于 MassBattle 特效批处理改造的 Niagara MCP 接口（UE 5.8）。

以 UE 5.8 的 Niagara 编辑器能力为完整功能基线，读取系统、发射器、渲染器、模块引脚和脚本图，再通过显式属性写入、堆栈输入与图编辑把现有效果接入 MassBattle 批处理。 改造过程使用源系统与目标系统的语义比较、图连接证据和编译诊断检查保留结果；写入和删除分别使用各自的公开工具。各函数说明其选择器、操作 JSON、保存行为及返回报告。
