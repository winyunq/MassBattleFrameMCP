MassBattleEffectAssetMCPApi.h

管理特效资产并配置批处理渲染器。

查询并识别 Niagara、Cascade、材质和蓝图等特效资产，读取类型化摘要或确定性文本，再执行复制、未保存副本回滚或显式删除。渲染器接口读写 MassBattle FX 渲染器类默认值，包括 Niagara 系统、Burst 数据通道、特效子类型和批量大小。 调用者从查询和检查结果取得真实资产路径与配置，再选择对应的资产操作或渲染配置工具。参数、默认行为和 JSON 返回结果在各公开函数中说明。

类

UMassBattleEffectAssetMCPApi

检查和管理特效资产。

提供资产发现、文本检查、复制和 MassBattle 特效渲染器默认值写入，由技能将这些基础操作组合为转换流程。

读取批处理特效渲染器默认值(目标类路径)

UMassBattleEffectAssetMCPApi::MCP_BatchFxReadRendererDefaults

读取批处理特效渲染器默认配置。

描述

MCP 工具：batch_fx_read_renderer_defaults。读取选定 MassBattle 特效渲染器类的类默认对象；新放置的渲染器 Actor 继承这些创作设置。

输入

名称类型说明
目标类路径TargetClassPathconst FString &解析为 AMassBattleFxRenderer 或其派生类的 Unreal 蓝图或类路径。

返回值

JSON 包含 success 和 defaults；类或类默认对象无法解析时返回 success=false/error。

函数

设置批处理特效渲染器默认值(目标类路径, Niagara 系统路径, Burst 数据通道路径, 子类型索引, 批量大小, 池化冷却时间, 保存资产)

UMassBattleEffectAssetMCPApi::MCP_BatchFxSetRendererDefaults

设置批处理特效渲染器默认配置。

描述

MCP 工具：batch_fx_set_renderer_defaults。更新类默认对象，必要时重新编译蓝图，将包标为已修改，并按选项保存。空系统或通道路径保留原引用；数值哨兵值保留相应原设置。

输入

名称类型说明
目标类路径TargetClassPathconst FString &待修改默认值的 MassBattle 特效渲染器蓝图或类路径。
Niagara 系统路径NiagaraSystemPathconst FString &NiagaraSystem 对象路径；空字符串保留现有系统。
Burst 数据通道路径NdcBurstFxPathconst FString &NiagaraDataChannelAsset 对象路径；空字符串保留现有 Burst 通道。
子类型索引SubTypeint32特效子类型索引；负数保留现有索引。
批量大小RenderBatchSizeint32正数为批量大小，非正数保留原值。MCP 工具默认值为 2048。
池化冷却时间PoolingCooldownfloat池化冷却时间，单位秒；负数保留原值。MCP 工具默认值为 3.0。
保存资产bSaveAssetsbool是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值

JSON 包含 success、class_path、niagara_system、ndc_burst_fx、subtype、render_batch_size、pooling_cooldown 和 saved。资产引用无效或保存失败时返回 success=false/error。

UMassBattleEffectAssetMCPApi::MCP_EffectAssetExportText

将特效资产导出为文本。

描述

MCP 工具：effect_asset_export_text。加载资产，在类型化摘要中包含反射属性和依赖信息，再生成用于详细阅读与比较的确定性文本；write_file 控制是否同时写入文件。

输入

名称类型说明
资产路径AssetPathconst FString &待导出特效资产的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。write_file 控制是否将文本写入磁盘。

返回值

JSON 包含资产摘要及 text；写入文件时另含 text_path。JSON 无效或加载、导出失败时返回 success=false 和 error。

将特效资产移入回收目录(资产路径, 选项 JSON)

UMassBattleEffectAssetMCPApi::MCP_EffectAssetSoftDelete

将资产移入回收目录。

描述

MCP 工具：effect_asset_soft_delete。生成回收目录移动报告并检查硬引用、软引用；有引用时，只有显式提供对应覆盖选项才允许移动。默认预览返回拟用目标路径；执行请求通过 AssetTools 移动资产并报告实际结果。

输入

名称类型说明
资产路径AssetPathconst FString &现有特效资产的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。dry_run 默认为 true，preview_only 也用于预览。trash_package_path/trash_root 指定目标目录；allow_referenced、allow_unsafe_asset_move/force 显式允许相应特殊移动。

返回值

JSON 包含 dry_run、source_path、applicable、blocked_reason 和 trash_path；执行后增加 moved 及实际 success/error 结果。

UMassBattleEffectAssetMCPApi::MCP_EffectDiscardUnsavedDuplicate

丢弃未保存的特效副本。

先通过 复制特效资产 设置 bSaveAssets=false，创建未保存副本。

描述

MCP 工具：effect_discard_unsaved_duplicate。仅丢弃当前会话跟踪的未保存副本；副本须仍已加载、位于已修改的 /Game/ 包中，并且尚未成为已持久化资产。用于保存前回滚失败的转换。

输入

名称类型说明
资产路径AssetPathconst FString &复制工具在当前编辑器会话中返回的未保存副本的完整对象路径。

返回值

JSON 包含 success、discarded、asset_path、package 和 deleted_count；未被跟踪、已卸载或包未被修改的副本返回 success=false/error。
