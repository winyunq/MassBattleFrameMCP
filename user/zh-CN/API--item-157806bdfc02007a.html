MassBattleEffectAssetMCPApi.h

用于特效资产检查、管理和批处理渲染配置的 MCP 接口。

查询并识别 Niagara、Cascade、材质和蓝图等特效资产，读取类型化摘要或确定性文本，再执行复制、未保存副本回滚或显式删除。渲染器接口读写 MassBattle FX 渲染器类默认值，包括 Niagara 系统、Burst 数据通道、特效子类型和批量大小。 调用者从查询和检查结果取得真实资产路径与配置，再选择对应的资产操作或渲染配置工具。参数、默认行为和 JSON 返回结果在各公开函数中说明。

类

UMassBattleEffectAssetMCPApi

Low-level effect asset MCP primitives.

These tools intentionally do not perform one-click conversion. They provide asset discovery, text inspection, duplication, and MassBattle FX renderer default writes so a skill can assemble a conversion workflow.

MCP Batch Fx Read Renderer Defaults(TargetClassPath)

UMassBattleEffectAssetMCPApi::MCP_BatchFxReadRendererDefaults

Read AMassBattleFxRenderer Blueprint class defaults used by newly placed actors.

描述

MCP tool: batch_fx_read_renderer_defaults. Reads the class-default object of the selected MassBattle FX renderer class. These defaults are the authoring settings inherited by newly placed renderer actors.

输入

名称类型说明
TargetClassPathconst FString &Unreal Blueprint/class path resolving to AMassBattleFxRenderer or a derived class.

返回值

JSON with success and defaults, or success=false/error if the class or default object cannot be resolved.

函数

MCP Batch Fx Set Renderer Defaults(TargetClassPath, NiagaraSystemPath, NdcBurstFxPath, SubType, RenderBatchSize, PoolingCooldown, bSaveAssets)

UMassBattleEffectAssetMCPApi::MCP_BatchFxSetRendererDefaults

Set AMassBattleFxRenderer Blueprint CDO defaults for a batched FX subtype.

描述

MCP tool: batch_fx_set_renderer_defaults. Updates the renderer class-default object, recompiles its Blueprint when applicable, marks the package dirty and optionally saves it. Empty system/channel paths keep the existing reference; numeric sentinel values keep the corresponding existing setting.

输入

名称类型说明
TargetClassPathconst FString &MassBattle FX renderer Blueprint/class path whose defaults will be edited.
NiagaraSystemPathconst FString &NiagaraSystem object path; an empty string keeps the existing system.
NdcBurstFxPathconst FString &NiagaraDataChannelAsset object path; an empty string keeps the current Burst channel.
SubTypeint32FX subtype index. A negative value keeps the existing index.
RenderBatchSizeint32Positive batch size, or a non-positive value to keep it. The MCP tool default is 2048.
PoolingCooldownfloatPooling cooldown in seconds; a negative value keeps it. The MCP tool default is 3.0.
bSaveAssetsboolWhether to save the modified or newly created assets to disk. The MCP tool supplies its documented save_assets default; false leaves changes in editor memory.

返回值

JSON with success, class_path, niagara_system, ndc_burst_fx, subtype, render_batch_size, pooling_cooldown and saved. Invalid asset references or save errors return success=false/error.

MCP Effect Asset Export Text(AssetPath, OptionsJson)

UMassBattleEffectAssetMCPApi::MCP_EffectAssetExportText

Export deterministic text for an effect-related asset.

描述

MCP tool: effect_asset_export_text. Loads the asset, includes reflected property/dependency information in its typed summary and produces a deterministic text representation for detailed comparison. write_file controls writing the text artifact in addition to returning it.

输入

名称类型说明
AssetPathconst FString &Unreal object path of the effect-related asset to export.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. write_file selects whether to write the exported text to disk.

返回值

JSON containing the asset summary and text, with text_path when written. Invalid JSON or a failed load/export returns success=false and error.

函数

MCP Effect Asset Soft Delete(AssetPath, OptionsJson)

UMassBattleEffectAssetMCPApi::MCP_EffectAssetSoftDelete

Move an unreferenced generic asset to trash; dry_run=true by default.

描述

MCP tool: effect_asset_soft_delete. Builds a trash-move report, checks hard/soft referencers and blocks a referenced asset unless the explicit corresponding override is supplied. The default dry run returns the proposed destination; an executable request uses AssetTools to move the asset and reports the outcome.

输入

名称类型说明
AssetPathconst FString &Unreal object path of the existing effect-related asset.
OptionsJsonconst FString &JSON object; pass {} to use the defaults. dry_run defaults to true; preview_only also requests a preview. trash_package_path/trash_root select the destination. allow_referenced and allow_unsafe_asset_move/force explicitly opt into the supported exceptional moves.

返回值

JSON with dry_run, source_path, applicable, blocked_reason and trash_path; execution adds moved and any success/error result.

MCP Effect Discard Unsaved Duplicate(AssetPath)

UMassBattleEffectAssetMCPApi::MCP_EffectDiscardUnsavedDuplicate

Discard only an unsaved in-memory duplicate created by this MCP editor session.

Create the unsaved duplicate with MCP Effect Duplicate Asset using bSaveAssets=false.

描述

MCP tool: effect_discard_unsaved_duplicate. Discards a duplicate only when this MCP editor session tracked it as unsaved, it is still loaded in a dirty /Game/ package, and it has not crossed the persisted-asset boundary. This supports rolling back a failed conversion before saving.

输入

名称类型说明
AssetPathconst FString &Exact object path returned by the duplicate tool for an unsaved duplicate in this editor session.

返回值

JSON with success, discarded, asset_path, package and deleted_count; an untracked, unloaded or non-dirty duplicate returns success=false/error.

函数

MCP Effect Duplicate Asset(SourceAssetPath, NewAssetName, PackagePath, bSaveAssets)

UMassBattleEffectAssetMCPApi::MCP_EffectDuplicateAsset

Duplicate an effect-related asset additively.

描述

MCP tool: effect_duplicate_asset. Uses AssetTools to duplicate the source asset into the requested package and name. The duplicate preserves the source-owned visual data. When left unsaved, it is tracked by this editor session so the matching discard tool can roll it back.

输入

名称类型说明
SourceAssetPathconst FString &Unreal object path of the existing source effect asset.
NewAssetNameconst FString &Name of the new duplicate asset.
PackagePathconst FString &Destination Unreal package folder, such as /Game/Effects.
bSaveAssetsboolWhether to save the modified or newly created assets to disk. The MCP tool supplies its documented save_assets default; false leaves changes in editor memory.

返回值

JSON with success, asset_path, package and saved, or success=false and error if loading, duplication or saving fails.
