函数

规划单位风格目录整理

UMassBattleStyleMCPApi::MCP_StylePlanOrganizeUnits

按风格计算单位资产的目标目录和移动清单。

描述

根据单位风格系列及风格索引计算目标目录，只生成供审阅的移动列表；此入口不执行 AssetTools 移动。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。target_root 指定整理根目录；单位扫描选项选择源资产。

返回值

target_root 下的资产移动建议，逐项列出源路径和目标路径；dry_run_only=true 表示这只是方案。

函数

汇总单位风格组织

UMassBattleStyleMCPApi::MCP_StyleSummarizeUnits

统计风格系列、风格索引和目录类别的单位分布。

描述

扫描选定单位，汇总创作风格索引、推断的风格系列和路径类别；返回组织数量，保留资产位置。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。使用单位扫描选项确定汇总范围。

返回值

单位总数，以及按风格系列、目录类别和风格索引统计的分布。

应用单位变更规划

UMassBattleUnitMCPApi::MCP_UnitApplyPlan

将已审阅方案中的改动写入单位资产。

提交已审阅的规划前，使用 预览单位规划差异 查看差异。

描述

加载已存储规划，拒绝不可应用的规划，再执行受支持的变更类型。结果记录实际应用的变化和所选保存行为。

输入

名称类型说明
规划标识PlanIdconst FString &已审阅并存储的单位变更规划标识。
保存资产bSaveAssetsbool是否将本次修改或创建的资产保存到磁盘。

返回值

已执行方案的标识、applied_diff 中的实际改动及 saved 保存状态；方案、修改或保存失败时报告对应错误。

函数

创建单位配置

UMassBattleUnitMCPApi::MCP_UnitCreate

以模板为起点创建单位配置或源 Actor。

描述

从默认或指定模板创建单位，并可合并初始创作数据。asset_type=source_actor 创建 Unit Source Actor 蓝图，其余普通路径创建单位配置；目标必须是尚未被占用的 Unreal 资产路径。

输入

名称类型说明
创建规格 JSONCreateSpecJsonconst FString &JSON 指定 unit_path/new_unit_path，或同时指定 asset_name、package_path。template_unit 选择模板，unit_data 提供初始数据。asset_type=source_actor 启用来源蓝图路径，export_path 配置其输出。
保存资产bSaveAssetsbool是否将本次修改或创建的资产保存到磁盘。

返回值

新资产的标识及保存结果；失败时说明目标路径冲突或初始数据合并问题。

函数

删除或回收单位配置

UMassBattleUnitMCPApi::MCP_UnitDelete

预览或执行单位资产删除方案。

描述

生成明确的单位删除规划。dry_run=true 返回 would_delete 和规划，保留资产原状；dry_run=false 经同一变更 API 应用可执行的规划。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。dry_run 默认为 true；删除模式及校验由显式单位删除规划处理。

返回值

待删除内容的 would_delete 预览或实际删除结果；dry_run 区分预览与执行，applicable 说明方案是否可执行。

函数

导出单位平衡表

UMassBattleUnitMCPApi::MCP_UnitExport

生成用于比较和调参的 JSON 或 CSV 平衡表。

描述

读取选定单位的平衡字段并写入 JSON 或 CSV 表格。未指定 output_path 时，文件保存到项目 Saved/MassBattleEditorMCP/Exports；响应给出输出文件和单位数量。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。format 选择 JSON 或 CSV，output_path 指定输出文件；单位扫描和字段选项决定表格内容。

返回值

导出文件的 output_path、格式及单位数量；失败时说明选项或文件保存问题。

UMassBattleUnitMCPApi::MCP_UnitGet

查看单位配置及源 Actor 的导出信息。

加载单位或 Unit Source Actor，返回与源码字段对应的创作 Data。默认简单视图省略运行时、系统和已弃用字段；来源 Actor 还报告 export_path、exported_unit 和 last_report。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。选择所需详细程度、对象视图和字段包含规则；响应报告 detail、default_ignore_policy。

返回值

单位的资产标识及 Data 中的配置内容；detail 标明本次采用的字段视图。

读取单位字段结构

UMassBattleUnitMCPApi::MCP_UnitGetSchema

确定单位局部写入可用的字段、类型和嵌套结构。

描述

生成 UMassBattleAgentConfigDataAsset 的可编辑属性结构，采用与单位读取相同的默认忽略规则。递归模式展开嵌套结构字段，供调用者按真实属性名编写补丁。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。recursive 默认为 true；递归时 depth 默认为 3，否则为 0，最终限制在 0..8。

返回值

适用的单位类型及可编辑字段定义，包括字段类型、嵌套结构和默认省略规则。

函数

列出单位配置

UMassBattleUnitMCPApi::MCP_UnitList

按路径筛选单位资产并查看平衡数据。

描述

扫描单位配置资产，按 query 筛选对象路径，返回精简的平衡数值摘要。load_fields 控制是否加载资产读取创作值；total_scanned 是文本筛选和数量限制前的候选数。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。query 是不区分大小写的路径文本，limit 限制在 1..2000，load_fields 默认为 true。

返回值

单位摘要列表及搜索范围；count 是本次返回条数，total_scanned 是筛选和数量限制前的候选数。

合并写入单位配置

UMassBattleUnitMCPApi::MCP_UnitMergeUpdate

局部修改单位并保留未提交的字段。

描述

先规划合并写入并检查 success、applicable，再自动应用返回的规划。未指定字段保留；校验阻止应用时直接返回规划结果。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
单位数据 JSONUnitDataJsonconst FString &与源码字段对应的局部单位创作数据。精确可编辑字段名从单位字段结构取得。
保存资产bSaveAssetsbool是否将本次修改或创建的资产保存到磁盘。

返回值

实际应用的字段改动及保存结果；修改方案不可执行时返回规划结果和问题。

规划单位合并写入

UMassBattleUnitMCPApi::MCP_UnitPlanMergeUpdate

在写入前检查局部修改将产生的字段差异。

描述

根据局部源码对应 JSON 生成并存储合并规划，保留未指定的单位字段。本入口不修改资产；applicable、merge_errors 说明变更能否应用。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
单位数据 JSONUnitDataJsonconst FString &使用源码属性名的局部单位 JSON，只包含需要修改的字段。Unit Source Actor 补丁还可包含 export_path。

返回值

已保存的更新方案；plan_id 用于后续查看或执行，diff 给出字段改动，applicable 与 merge_errors 说明方案能否执行。

函数

描述

输入

名称类型说明
规划标识PlanIdconst FString &单位规划操作返回的 plan_id。

返回值

完整方案及其字段差异；applicable 说明是否可执行，方案不存在或无法读取时返回错误。
