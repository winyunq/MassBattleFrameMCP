应用单位变更规划(规划标识, 保存资产)

UMassBattleUnitMCPApi::MCP_UnitApplyPlan

应用已审阅的单位变更规划，并按选项保存资产。

提交已审阅的规划前，使用 预览单位规划差异 查看差异。

描述

MCP 工具：unit_apply_plan。加载已存储规划，拒绝不可应用的规划，再执行受支持的变更类型。结果记录实际应用的变化和所选保存行为。

输入

名称类型说明
规划标识PlanIdconst FString &已审阅并存储的单位变更规划标识。
保存资产bSaveAssetsbool是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值

JSON 包含变更结果、plan_id、saved 和 applied_diff；规划无效、变更或保存失败时返回 success=false 和 error。

创建单位配置(创建规格 JSON, 保存资产)

UMassBattleUnitMCPApi::MCP_UnitCreate

从默认模板或指定模板创建 MassBattle 单位。

描述

MCP 工具：unit_create。从默认或指定模板创建单位，并可合并初始创作数据。asset_type=source_actor 创建 Unit Source Actor 蓝图，其余普通路径创建单位配置；目标必须是尚未被占用的 Unreal 资产路径。

输入

名称类型说明
创建规格 JSONCreateSpecJsonconst FString &JSON 指定 unit_path/new_unit_path，或同时指定 asset_name、package_path。template_unit 选择模板，unit_data 提供初始数据。asset_type=source_actor 启用来源蓝图路径，export_path 配置其输出。
保存资产bSaveAssetsbool是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值

创建或应用结果 JSON，标明新资产及 saved 状态。目标无效、已被占用或初始数据合并失败时返回 success=false 和 error。

UMassBattleUnitMCPApi::MCP_UnitDelete

显式删除或软删除 MassBattle 单位；dry_run 默认为 true。

描述

MCP 工具：unit_delete。生成明确的单位删除规划。dry_run=true 返回 would_delete 和规划，保留资产原状；dry_run=false 经同一变更 API 应用可执行的规划。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。dry_run 默认为 true；删除模式及校验由显式单位删除规划处理。

返回值

返回包含 dry_run、would_delete 的删除规划，或实际删除结果。JSON 无效或规划不可应用时报告 success=false/error 或 applicable=false。

返回值

描述

MCP 工具：unit_write。先规划合并写入并检查 success、applicable，再自动应用返回的规划。未指定字段保留；校验阻止应用时直接返回规划结果。

保存资产bSaveAssetsbool是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值
