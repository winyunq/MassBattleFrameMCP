UMassBattleStyleMCPApi::MCP_StylePlanOrganizeUnits

描述

MCP 工具：style_plan_organize_units。根据单位风格系列及风格索引计算目标目录，只生成供审阅的移动列表；此入口不执行 AssetTools 移动。

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。target_root 指定整理根目录；单位扫描选项选择源资产。

返回值

JSON 包含 success、plan_type、target_root、dry_run_only=true，以及给出源和目标路径的 moves。

应用单位变更规划

UMassBattleUnitMCPApi::MCP_UnitApplyPlan

执行单位变更方案。

提交已审阅的规划前，使用 预览单位规划差异 查看差异。

描述

MCP 工具：unit_apply_plan。加载已存储规划，拒绝不可应用的规划，再执行受支持的变更类型。结果记录实际应用的变化和所选保存行为。

输入

名称类型说明
规划标识PlanIdconst FString &已审阅并存储的单位变更规划标识。
保存资产bSaveAssetsbool是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值

JSON 包含变更结果、plan_id、saved 和 applied_diff；规划无效、变更或保存失败时返回 success=false 和 error。

函数

创建单位配置

UMassBattleUnitMCPApi::MCP_UnitCreate

从模板创建单位。

描述

MCP 工具：unit_create。从默认或指定模板创建单位，并可合并初始创作数据。asset_type=source_actor 创建 Unit Source Actor 蓝图，其余普通路径创建单位配置；目标必须是尚未被占用的 Unreal 资产路径。

输入

名称类型说明
创建规格 JSONCreateSpecJsonconst FString &JSON 指定 unit_path/new_unit_path，或同时指定 asset_name、package_path。template_unit 选择模板，unit_data 提供初始数据。asset_type=source_actor 启用来源蓝图路径，export_path 配置其输出。
保存资产bSaveAssetsbool是否将修改或新建的资产保存到磁盘。MCP 工具采用其声明的 save_assets 默认值；false 时只保留在编辑器内存中。

返回值

创建或应用结果 JSON，标明新资产及 saved 状态。目标无效、已被占用或初始数据合并失败时返回 success=false 和 error。

函数

删除或回收单位配置

UMassBattleUnitMCPApi::MCP_UnitDelete

删除单位配置资产。

描述

MCP 工具：unit_delete。生成明确的单位删除规划。dry_run=true 返回 would_delete 和规划，保留资产原状；dry_run=false 经同一变更 API 应用可执行的规划。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。dry_run 默认为 true；删除模式及校验由显式单位删除规划处理。

返回值

返回包含 dry_run、would_delete 的删除规划，或实际删除结果。JSON 无效或规划不可应用时报告 success=false/error 或 applicable=false。

导出单位平衡表

UMassBattleUnitMCPApi::MCP_UnitExport

导出单位平衡表。

描述

MCP 工具：unit_export。读取选定单位的平衡字段并写入 JSON 或 CSV 表格。未指定 output_path 时，文件保存到项目 Saved/MassBattleEditorMCP/Exports；响应给出输出文件和单位数量。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。format 选择 JSON 或 CSV，output_path 指定输出文件；单位扫描和字段选项决定表格内容。

返回值

JSON 包含 success、format、output_path 和 unit_count。选项无效或文件保存失败时返回 success=false 和 error。

查找单位制作所需的资产。

读取单位配置

UMassBattleUnitMCPApi::MCP_UnitGet

读取单位配置。

描述

MCP 工具：unit_get。加载单位或 Unit Source Actor，返回与源码字段对应的创作 Data。默认简单视图省略运行时、系统和已弃用字段；来源 Actor 还报告 export_path、exported_unit 和 last_report。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。选择所需详细程度、对象视图和字段包含规则；响应报告 detail、default_ignore_policy。

返回值

JSON 包含 success、AssetName、ObjectPath、Class、detail 和 Data。JSON 无效或单位无法解析时返回 success=false 和 error。

UMassBattleUnitMCPApi::MCP_UnitGetSchema

读取单位的可编辑字段。

描述

MCP 工具：unit_get_schema。生成 UMassBattleAgentConfigDataAsset 的可编辑属性结构，采用与单位读取相同的默认忽略规则。递归模式展开嵌套结构字段，供调用者按真实属性名编写补丁。

输入

名称类型说明
选项 JSONOptionsJsonconst FString &JSON 对象；{} 使用默认选项。recursive 默认为 true；递归时 depth 默认为 3，否则为 0，最终限制在 0..8。

返回值

列出单位配置资产。

返回值

规划单位合并写入

UMassBattleUnitMCPApi::MCP_UnitPlanMergeUpdate

预览单位配置变更。

描述

MCP 工具：unit_plan_write。根据局部源码对应 JSON 生成并存储合并规划，保留未指定的单位字段。本入口不修改资产；applicable、merge_errors 说明变更能否应用。

输入

名称类型说明
单位路径UnitPathconst FString &现有 MassBattle 单位配置或受支持 Unit Source Actor 蓝图的 Unreal 对象路径。
单位数据 JSONUnitDataJsonconst FString &使用源码属性名的局部单位 JSON，只包含需要修改的字段。Unit Source Actor 补丁还可包含 export_path。

返回值

JSON 包含 plan_id、plan_path、merge_semantics、patches、diff、merge_errors 和 applicable。JSON 无效、资产无法解析或没有可合并字段时返回 success=false 和 error。
